# Промпт для агента: импорт контента Scenario в Firestore / Storage

**Назначение:** шаблон запроса в чат Cursor (или другому агенту), чтобы **загрузить или обновить** кураторский контент без админки, в соответствии с [системными требованиями](system-requirements.md) (модель §4, **CR-4**, **CR-4.1**, **CR-5**).

**Правила проекта:** см. `.cursor/rules/scenario-content-import.mdc` и навык `.cursor/skills/scenario-firestore-content/SKILL.md`.

---

## Как использовать

1. Подготовьте или отредактируйте файлы в `data/content/` (JSON по согласованной схеме — после появления ADR-010).
2. Вставьте ниже промпт в чат, подставив свои детали в `[квадратные скобки]`.
3. Убедитесь, что для импорта настроены **учётные данные** Firebase (service account или `firebase login` для CLI — как решит tech lead в скрипте).

---

## Промпт (скопировать)

```
Ты работаешь в репозитории Scenario (Flutter + Firebase).

Задача: [создать новый сценарий / обновить игру / загрузить изображения в Storage / пересобрать денормализованный документ home_feed — выбери одно].

Исходные данные:
- Файл(ы): [укажи пути, например data/content/scenarios/foo.json]
- Окружение: [dev / staging / production]

Требования:
1. Соблюдай docs/system-requirements.md §4 (игры, сценарии, связи scenario_games, enums CR-4.1, карусель CR-5).
2. Slug: автоматически из title — транслитерация в латиницу, проверка уникальности в коллекции.
3. Тексты пользователя — plain text (A-4a СТ), без Markdown в клиенте.
4. Минимум один слайд карусели с frameType teaser.
5. Не записывай черновики в коллекции, читаемые публичным клиентом — только опубликованные представления согласно Security Rules.

Сделай:
- Валидацию JSON по схеме (или перечисли, чего не хватает в репозитории для валидации).
- Обнови или создай скрипт импорта в tools/ при необходимости.
- Команды для безопасного запуска (без вывода секретов в лог).

Если схема коллекций ещё не зафиксирована в коде — предложи минимальный diff к документу ADR или к константам имён коллекций и остановись с чеклистом для tech lead.
```

---

## Заметки

- Пока **ADR-010** не принят, агент может предложить **черновик** имён коллекций, согласованный с §4 СТ.
- Загрузка бинарных файлов в Storage обычно выполняется **скриптом** с локальными путями к файлам; в Git кладутся только ссылки после upload или плейсхолдеры — политика репозитория решается tech lead.
