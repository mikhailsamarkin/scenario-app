# Тест-кейсы: Веб-fallback: OG и сохранение UTM

## Обзор

- Цель: проверить корректные OG-теги и контент страницы сценария для пользователя без МП и сохранение UTM при цепочке редиректов (A-25).
- Вне scope: минимальный релиз без сайта — вместе с E4.

## Матрица трассировки AC → тест-кейсы

| AC    | TC-ID        | Кратко |
|-------|--------------|--------|
| AC-01 | TC-01        | Страница и OG из данных E1-04 |
| AC-02 | TC-02        | UTM после редиректа |

## Тест-кейсы

### TC-01 — Просмотр HTML: og:title, og:image, og:description

| Поле | Значение |
|------|----------|
| **Приоритет** | P0 |
| **Слой** | integration |
| **Покрывает** | AC-01 |
| **Тип** | positive |

**Предусловия:** Сайт задеплоен; сценарий с заполненными OG-полями.

**Шаги**

1. Запросить HTML страницы сценария.
2. Распарсить meta og:* и сравнить с данными контента.

**Ожидаемый результат:** OG соответствуют E1-04 и E4; контент страницы читаем (FR-W-4).

**Заметки для автоматизации:** Playwright `page.content()` + cheerio.

---

### TC-02 — Редирект с сохранением UTM

| Поле | Значение |
|------|----------|
| **Приоритет** | P0 |
| **Слой** | integration |
| **Покрывает** | AC-02 |
| **Тип** | positive |

**Предусловия:** Настроена цепочка редиректов (например www → apex или http → https), если есть по инфраструктуре.

**Шаги**

1. Запросить URL с UTM-параметрами, следовать редиректам.
2. Проверить финальный URL на наличие тех же UTM (A-25).

**Ожидаемый результат:** UTM не теряются.
