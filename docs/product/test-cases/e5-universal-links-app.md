# Тест-кейсы: Universal Links / App Links: открытие сценария в приложении

## Обзор

- Цель: проверить открытие HTTPS-ссылки на сценарий в установленном приложении с корректным `scenarioId` и валидность AASA / Digital Asset Links (A-23, A-24).
- Вне scope: минимальный релиз может обойтись без полного UL; веб-fallback — E5-03.

## Матрица трассировки AC → тест-кейсы

| AC    | TC-ID        | Кратко |
|-------|--------------|--------|
| AC-01 | TC-01        | Ссылка → приложение, верный сценарий |
| AC-02 | TC-02        | Валидация AASA и assetlinks |

## Тест-кейсы

### TC-01 — HTTPS ссылка на сценарий открывает МП

| Поле | Значение |
|------|----------|
| **Приоритет** | P0 |
| **Слой** | e2e |
| **Покрывает** | AC-01 |
| **Тип** | positive |

**Предусловия:** МП установлен; ссылка вида `https://scenario-games.ru/...` на опубликованный сценарий.

**Шаги**

1. Открыть ссылку из Safari (iOS) / Chrome intent (Android).
2. Подтвердить открытие в приложении.
3. Проверить экран сценария и соответствие id.

**Ожидаемый результат:** Приложение открыто с нужным `scenarioId` (A-24).

**Заметки для автоматизации:** Частично manual на реальных устройствах; проверка диплинка через `adb`/`xcrun`.

---

### TC-02 — Проверка apple-app-site-association

| Поле | Значение |
|------|----------|
| **Приоритет** | P0 |
| **Слой** | integration |
| **Покрывает** | AC-02 |
| **Тип** | positive |

**Шаги**

1. GET `https://scenario-games.ru/.well-known/apple-app-site-association` (без редиректа на HTML).
2. Проверить JSON: team id, bundle id, paths.

**Ожидаемый результат:** Файл валиден и соответствует билду iOS (A-23).

**Заметки для автоматизации:** Скрипт в CI с проверкой схемы.

---

### TC-03 — Проверка Digital Asset Links

| Поле | Значение |
|------|----------|
| **Приоритет** | P0 |
| **Слой** | integration |
| **Покрывает** | AC-02 |
| **Тип** | positive |

**Шаги**

1. GET `https://scenario-games.ru/.well-known/assetlinks.json`.
2. Сверить package name и SHA-256 сертификата с релизной сборкой Android.

**Ожидаемый результат:** Файл валиден для App Links.

---

### TC-04 — Ссылка без установленного МП

| Поле | Значение |
|------|----------|
| **Приоритет** | P1 |
| **Слой** | e2e |
| **Покрывает** | AC-01 |
| **Тип** | edge |

**Предусловия:** МП не установлен (или отключено перехватывание).

**Шаги**

1. Открыть ту же HTTPS-ссылку в браузере.

**Ожидаемый результат:** Открывается веб-страница (E5-03 / E4), без краша браузера.

## Регресс и смоук

- **Smoke:** TC-02, TC-03 (CI) + TC-01 на релизной кандидате.
- **Регресс полный:** TC-01–TC-04 при смене bundle id, подписи или домена.
