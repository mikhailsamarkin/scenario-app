# Тест-кейсы: Склейка МП — точка входа и навигация Home → Scenario → Game

## Обзор

- Цель: проверить, что приложение запускается с главного экрана (витрины) и переходы Home → Scenario → Game работают через реальный репозиторий (A-15, A-11, A-38).
- Вне scope: онбординг (E3-01), офлайн/кэш/обновление (E2-04/05/06).

## Матрица трассировки AC → тест-кейсы

| AC    | TC-ID        | Кратко |
|-------|--------------|--------|
| AC-01 | TC-01        | Точка входа — витрина из home_feed/main |
| AC-02 | TC-02, TC-03 | Переходы Home → Scenario → Game |

## Тест-кейсы

### TC-01 — Запуск приложения показывает витрину из home_feed

| Поле | Значение |
|------|----------|
| **Приоритет** | P0 |
| **Слой** | widget |
| **Покрывает** | AC-01 |
| **Тип** | positive |

**Предусловия:** Флаг «онбординг пройден» установлен (иначе сначала онбординг, E3-01); в тестовом проекте есть опубликованные сценарии.

**Шаги**

1. Запустить приложение.
2. Дождаться загрузки главного экрана.
3. Проверить, что отображается витрина сценариев из `home_feed/main`.

**Ожидаемый результат:** Главный экран — витрина сценариев (FR-M-1, A-15).

**Заметки для автоматизации:** `ScenarioApp` с фейковым `AggregateRepository`; `find.text` заголовка витрины.

**Предусловия:** Витрина загружена; известен id сценария карточки.

### TC-04 — Чтение через реальный репозиторий (A-11, A-38)

| Поле | Значение |
|------|----------|
| **Приоритет** | P1 |
| **Слой** | integration |
| **Покрывает** | AC-01, AC-02 |
| **Тип** | positive |

**Предусловия:** dev-проект с опубликованным контентом; правила Firestore задеплоены.

**Шаги**

1. Запустить приложение на dev (реальный Firestore).
2. Пройти Home → Scenario → Game.
3. Проверить, что данные читаются из публичных агрегатов без permission-denied.

**Ожидаемый результат:** Чтение публичных агрегатов работает (A-11, A-38); черновики недоступны.

**Заметки для автоматизации:** Требует dev-проекта и задеплоенных правил.
