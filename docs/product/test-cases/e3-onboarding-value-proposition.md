# Тест-кейсы: Онбординг: ценность «ситуация → игры»

## Обзор

- Цель: проверить понятность ценности продукта на первом запуске и отсутствие блокировки витрины при отказе от push.
- Вне scope: обязательная подписка на topic (E3-02), дневные пуши (E3-03).

## Матрица трассировки AC → тест-кейсы

| AC    | TC-ID        | Кратко |
|-------|--------------|--------|
| AC-01 | TC-01        | Понятна модель «ситуация → подборка» |
| AC-02 | TC-02        | Отказ от push не блокирует контент |

## Тест-кейсы

### TC-01 — Прохождение онбординга: ценность ясна

| Поле | Значение |
|------|----------|
| **Приоритет** | P0 |
| **Слой** | manual-only |
| **Покрывает** | AC-01 |
| **Тип** | positive |

**Предусловия:** Чистая установка; первый запуск.

**Шаги**

1. Открыть приложение.
2. Пройти все шаги онбординга, читая тексты/иллюстрации.
3. По чеклисту убедиться, что раскрыта связь «ситуация → подборка игр» (UJ-4).

**Ожидаемый результат:** Понятная ценность без обязательного внешнего гайда; формулировки согласованы с копирайтом.

**Заметки для автоматизации:** Не автоматизировать субъективную оценку; опционально проверка наличия ключевых строк в виджет-тесте.

---

### TC-02 — Отклонение push: доступ к витрине сохраняется

| Поле | Значение |
|------|----------|
| **Приоритет** | P0 |
| **Слой** | e2e |
| **Покрывает** | AC-02 |
| **Тип** | positive |

**Предусловия:** На шаге запроса разрешения на уведомления (если показывается в том же релизе).

**Шаги**

1. На запросе уведомлений выбрать «Не разрешать» / закрыть.
2. Завершить онбординг.
3. Убедиться, что открывается главный экран / витрина с контентом.

**Ожидаемый результат:** Доступ к контенту не заблокирован; нет бесконечного цикла запроса push.

**Заметки для автоматизации:** На симуляторах iOS диалоги могут отличаться — учесть в матрице.

---

### TC-03 — Офлайн после онбординга: состояние по FR-M-3

| Поле | Значение |
|------|----------|
| **Приоритет** | P1 |
| **Слой** | e2e |
| **Покрывает** | AC-01 (контекст) |
| **Тип** | edge |

**Предусловия:** После онбординга нет сети.

**Шаги**

1. Завершить онбординг при отключённой сети (или отключить сразу после).
2. Проверить сообщение о загрузке контента / офлайне.

**Ожидаемый результат:** Понятное состояние; согласовано с E2-05.
