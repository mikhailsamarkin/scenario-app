# Тест-кейсы: ЧПУ и метаданные страниц сценария и игры

## Обзор

- Цель: проверить генерацию отдельных URL для сценария и игры с корректными title/description и доступность для индексации (SR-SEO-1).
- Вне scope: минимальный первый релиз без сайта — кейсы для будущего E4.

## Матрица трассировки AC → тест-кейсы

| AC    | TC-ID        | Кратко |
|-------|--------------|--------|
| AC-01 | TC-01        | Отдельные URL и метаданные после SSG |
| AC-02 | TC-02        | Робот получает индексируемый контент |

## Тест-кейсы

### TC-01 — Билд SSG: маршруты сценария и игры с title/description

| Поле | Значение |
|------|----------|
| **Приоритет** | P0 |
| **Слой** | integration |
| **Покрывает** | AC-01 |
| **Тип** | positive |

**Предусловия:** Опубликованные сценарий и игра с полями из E1-04; выполнен билд Next.js SSG.

**Тестовые данные:** Ожидаемые slug из данных.

**Шаги**

1. Открыть сгенерированные HTML или пройти по URL сценария и игры.
2. Проверить `<title>` и meta description в исходнике страницы.
3. Сверить с данными контента.

**Ожидаемый результат:** Существуют отдельные ЧПУ; метаданные соответствуют Firestore (FR-W-2, SR-SEO-1).

**Заметки для автоматизации:** Playwright/curl на артефакте билда в CI.

### TC-02 — Доступность для поискового робота (noindex отсутствует где не нужно)

| Поле | Значение |
|------|----------|
| **Приоритет** | P0 |
| **Слой** | integration |
| **Покрывает** | AC-02 |
| **Тип** | positive |

**Предусловия:** Страницы публичного контента.

**Шаги**

1. Запросить страницу с User-Agent поискового робота (или проверить headers/meta).
2. Убедиться в отсутствии запрета индексации для опубликованного контента согласно SR-SEO-1.

**Ожидаемый результат:** Контент доступен для индексации при соблюдении политики SEO.
