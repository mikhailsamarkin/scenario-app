# Тест-кейсы: События block_view с порогом viewport

## Обзор

- Цель: проверить срабатывание `block_view` при ≥50% видимой площади и удержании ≥300 ms (A-36), одно срабатывание на блок за сессию экрана, отсутствие дубликата при повторном скролле.
- Вне scope: сторонние heatmaps.

## Матрица трассировки AC → тест-кейсы

| AC    | TC-ID        | Кратко |
|-------|--------------|--------|
| AC-01 | TC-01        | Порог 50% и 300 ms |
| AC-02 | TC-02        | Нет повторного события за сессию экрана |

## Тест-кейсы

### TC-01 — Блок становится видимым наполовину и дольше 300 ms

| Поле | Значение |
|------|----------|
| **Приоритет** | P0 |
| **Слой** | integration |
| **Покрывает** | AC-01 |
| **Тип** | positive |

**Предусловия:** Экран сценария с именованными блоками; Fake Analytics.

**Шаги**

1. Медленно скроллить до появления блока так, чтобы видимая площадь пересекла 50%.
2. Удержать ≥300 ms.
3. Проверить одно событие `block_view` с корректным `block_id`.

**Ожидаемый результат:** Событие отправлено один раз при выполнении порога (A-36).

**Заметки для автоматизации:** Widget-тест с контролируемым viewport; мок таймера.

---

### TC-02 — Быстрый проскок блока без удержания 300 ms

| Поле | Значение |
|------|----------|
| **Приоритет** | P0 |
| **Слой** | integration |
| **Покрывает** | AC-01 |
| **Тип** | negative |

**Шаги**

1. Проскроллить блок мимо экрана быстрее 300 ms при кратковременном пересечении 50%.

**Ожидаемый результат:** Событие не отправлено (или по политике удержания — уточнить граничный случай с PO).

---

### TC-03 — Уход со страницы и возврат: сессия экрана сбрасывается

| Поле | Значение |
|------|----------|
| **Приоритет** | P0 |
| **Слой** | e2e |
| **Покрывает** | AC-02 |
| **Тип** | positive |

**Шаги**

1. Вызвать `block_view` для блока A.
2. Уйти на другой экран и вернуться на сценарий.
3. Снова выполнить условия порога для блока A.

**Ожидаемый результат:** По согласованию со СТ — новая «сессия экрана» может снова отправить событие; если нет — зафиксировать ожидание из A-36.

**Заметки:** Уточнить определение «сессии экрана» в коде — должно совпадать со стори (одно на блок за сессию).

---

### TC-04 — Скролл туда-обратно без ухода со страницы

| Поле | Значение |
|------|----------|
| **Приоритет** | P0 |
| **Слой** | integration |
| **Покрывает** | AC-02 |
| **Тип** | positive |

**Шаги**

1. Выполнить TC-01 для блока B.
2. Ускроллить вверх и снова вниз к блоку B на том же экране.

**Ожидаемый результат:** Второго `block_view` для того же `block_id` нет за ту же сессию экрана.

## Регресс и смоук

- **Smoke:** TC-01, TC-04.
- **Регресс полный:** TC-01–TC-04 при смене вёрстки E2 или порогов A-36.

## Допущения

- Список `block_id` зафиксирован рядом с A-35.
