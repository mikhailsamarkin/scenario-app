# Тест-кейсы: «Сценарии прошлого» для снятых с витрины подборок

## Обзор

- Цель: проверить доступность снятых с витрины сценариев в разделе «Сценарии прошлого» и отсутствие дублирования с активной витриной (CR-3, FR-M-1).
- Вне scope: минимальный первый релиз без раздела.

## Матрица трассировки AC → тест-кейсы

| AC    | TC-ID        | Кратко |
|-------|--------------|--------|
| AC-01 | TC-01        | Снятый сценарий в архиве, не на витрине |
| AC-02 | TC-02        | Нет дубля между витриной и «прошлым» |

## Тест-кейсы

### TC-01 — Сценарий снят с витрины: виден в «Сценарии прошлого»

| Поле | Значение |
|------|----------|
| **Приоритет** | P0 |
| **Слой** | e2e |
| **Покрывает** | AC-01 |
| **Тип** | positive |

**Предусловия:** В данных сценарий помечен как снятый с витрины; остаётся опубликованным для архива.

**Шаги**

1. Открыть раздел «Сценарии прошлого» (или эквивалент по копирайту).
2. Найти сценарий по названию.
3. Открыть карточку.

**Ожидаемый результат:** Сценарий доступен; контент открывается (CR-3).

---

### TC-02 — Активная витрина не показывает архивный сценарий

| Поле | Значение |
|------|----------|
| **Приоритет** | P0 |
| **Слой** | e2e |
| **Покрывает** | AC-01 |
| **Тип** | negative |

**Шаги**

1. Открыть главный экран (витрину).
2. Убедиться, что снятый сценарий отсутствует в списке активных карточек.

**Ожидаемый результат:** Нет отображения архивного сценария как актуальной витринной карточки.

---

### TC-03 — Нет дублирования при просмотре только «прошлого»

| Поле | Значение |
|------|----------|
| **Приоритет** | P1 |
| **Слой** | e2e |
| **Покрывает** | AC-02 |
| **Тип** | positive |

**Шаги**

1. Составить список id на витрине и в архиве.
2. Проверить пересечение множеств.

**Ожидаемый результат:** Сценарий не одновременно в активной витрине и как дубль в другом виде; логика CR-3 соблюдена.

---

### TC-04 — Аналитика source=past (E6-02)

| Поле | Значение |
|------|----------|
| **Приоритет** | P1 |
| **Слой** | integration |
| **Покрывает** | AC-01 |
| **Тип** | positive |

**Шаги**

1. Открыть сценарий из архива.
2. Проверить `source=past` в событии открытия.

**Ожидаемый результат:** Соответствует реестру.
