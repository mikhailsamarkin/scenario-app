# Тест-кейсы: CTA установки мобильного приложения

## Обзор

- Цель: проверить наличие заметных ссылок в сторы на контентных страницах и на главной (FR-W-3); клики учитываются в метриках (use-cases §6.2).
- Вне scope: атрибуция через MMP.

## Матрица трассировки AC → тест-кейсы

| AC    | TC-ID        | Кратко |
|-------|--------------|--------|
| AC-01 | TC-01, TC-02 | CTA на страницах сценария/игры |
| AC-02 | TC-03        | CTA на главной (шапка/подвал) |

## Тест-кейсы

### TC-01 — CTA на странице сценария

| Поле | Значение |
|------|----------|
| **Приоритет** | P0 |
| **Слой** | e2e |
| **Покрывает** | AC-01 |
| **Тип** | positive |

**Предусловия:** Сайт развёрнут; страница сценария доступна.

**Шаги**

1. Открыть страницу сценария.
2. Найти блок/шапку/подвал с CTA установки МП по макету.
3. Проверить, что ссылки ведут на корректные store URLs (iOS/Android).

**Ожидаемый результат:** CTA заметен и кликабелен (FR-W-3).

**Заметки для автоматизации:** `getByRole('link', { name: ... })` по доступному имени.
