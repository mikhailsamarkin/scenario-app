# Тест-кейсы: Группы смысла на главном экране

## Обзор

- Цель: проверить отображение групп смысла с сервера и корректный список сценариев при входе в группу (БТ §7.1, FR-M-1).
- Вне scope: минимальный первый релиз без групп.

## Матрица трассировки AC → тест-кейсы

| AC    | TC-ID        | Кратко |
|-------|--------------|--------|
| AC-01 | TC-01        | Группы и состав как на сервере |
| AC-02 | TC-02        | Экран группы: сценарии по конфигурации |

## Тест-кейсы

### TC-01 — Главный экран: группы из данных

| Поле | Значение |
|------|----------|
| **Приоритет** | P0 |
| **Слой** | e2e |
| **Покрывает** | AC-01 |
| **Тип** | positive |

**Предусловия:** В тестовых данных заданы группы смысла; не хардкод в клиенте.

**Шаги**

1. Открыть главный экран.
2. Сравнить список групп и порядок с эталоном из API/Firestore.

**Ожидаемый результат:** Состав и порядок соответствуют серверу (БТ §7.1).

**Заметки для автоматизации:** Фикстура JSON home с группами.

---

### TC-02 — Тап по группе: список сценариев

| Поле | Значение |
|------|----------|
| **Приоритет** | P0 |
| **Слой** | e2e |
| **Покрывает** | AC-02 |
| **Тип** | positive |

**Шаги**

1. Тапнуть по группе «вдвоём» (или тестовому названию).
2. Сверить список сценариев с контентной конфигурацией.

**Ожидаемый результат:** Отображаются только сценарии, относящиеся к группе.
