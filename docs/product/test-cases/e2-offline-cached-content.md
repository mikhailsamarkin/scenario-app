# Тест-кейсы: Офлайн: открытие ранее загруженного контента

## Обзор

- Цель: проверить чтение витрины/сценария/игры из локального кэша без сети и понятное состояние при первом запуске без сети и пустом кэше.
- Вне scope: контент, никогда не открывавшийся онлайн (ожидаемое ограничение).

## Матрица трассировки AC → тест-кейсы

| AC    | TC-ID        | Кратко |
|-------|--------------|--------|
| AC-01 | TC-01, TC-02 | Офлайн после онлайн-визита без фатальной ошибки |
| AC-02 | TC-03        | Первый запуск офлайн: empty state |

## Тест-кейсы

### TC-01 — Витрина из кэша в авиарежиме

| Поле | Значение |
|------|----------|
| **Приоритет** | P0 |
| **Слой** | e2e |
| **Покрывает** | AC-01 |
| **Тип** | positive |

**Предусловия:** Пользователь открыл главный экран при включённой сети; данные закэшированы.

**Шаги**

1. Включить режим полёта / отключить сеть на устройстве.
2. Закрыть и открыть приложение (или перейти на главный экран).
3. Проверить отображение списка сценариев из кэша.

**Ожидаемый результат:** Витрина открывается; нет необработанного исключения (FR-M-3, NFR-SR-3).

**Заметки для автоматизации:** Эмулятор с toggle network; возможны флаки на iOS — повторять прогон.

---

### TC-02 — Сценарий и игра из кэша офлайн

| Поле | Значение |
|------|----------|
| **Приоритет** | P0 |
| **Слой** | e2e |
| **Покрывает** | AC-01 |
| **Тип** | positive |

**Предусловия:** Онлайн открыты экраны сценария и игры для кэширования.

**Шаги**

1. Офлайн: открыть тот же сценарий из истории/навигации (если доступно) или из списка.
2. Перейти к игре из списка офлайн.

**Ожидаемый результат:** Контент отображается из кэша; при отсутствии части медиа — контролируемый fallback (UC-07).

---

### TC-03 — Первый запуск без сети и пустой кэш

| Поле | Значение |
|------|----------|
| **Приоритет** | P0 |
| **Слой** | e2e |
| **Покрывает** | AC-02 |
| **Тип** | negative |

**Предусловия:** Чистая установка или сброс данных приложения; сеть выключена до первого запуска.

**Шаги**

1. Запустить приложение первый раз офлайн.
2. Проверить экран состояния «нет данных / нет сети» (копирайт по дизайну).

**Ожидаемый результат:** Понятное сообщение; нет краша; основной контент не показывается как пустой без объяснения.

**Заметки для автоматизации:** `manual-only` если сложно сбросить кэш в CI — отметить в отчёте.

## Регресс и смоук

- **Smoke:** TC-01.
- **Регресс полный:** TC-01–TC-03 при изменении persistence или кэша изображений (E2-06).
