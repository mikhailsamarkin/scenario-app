# Тест-кейсы: Аналитика воронки шаринга

## Обзор

- Цель: проверить отправку события при тапе «Поделиться» и событие успешного выбора канала (если доступно на платформе) по схеме E6-01 и БТ §11.1 п.20–22.
- Вне scope: полная атрибуция установок через MMP.

## Матрица трассировки AC → тест-кейсы

| AC    | TC-ID        | Кратко |
|-------|--------------|--------|
| AC-01 | TC-01        | Событие попытки share |
| AC-02 | TC-02        | Событие успешного share |

## Тест-кейсы

### TC-01 — Тап «Поделиться»: событие попытки

| Поле | Значение |
|------|----------|
| **Приоритет** | P0 |
| **Слой** | integration |
| **Покрывает** | AC-01 |
| **Тип** | positive |

**Предусловия:** DebugView GA4/Firebase Analytics; имя события по реестру A-35 / E6-01.

**Шаги**

1. Открыть экран сценария.
2. Тапнуть «Поделиться».
3. В DebugView найти событие попытки (БТ §11.1 п.20).

**Ожидаемый результат:** Событие отправлено с ожидаемыми параметрами (`scenario_id` и др. по схеме).

**Заметки для автоматизации:** Мок analytics в unit; e2e с тестовым логгером.

---

### TC-02 — Выбор канала в share sheet: успешный share

| Поле | Значение |
|------|----------|
| **Приоритет** | P1 |
| **Слой** | manual-only |
| **Покрывает** | AC-02 |
| **Тип** | positive |

**Предусловия:** Платформа позволяет получить callback после выбора канала (iOS/Android различаются).

**Шаги**

1. Открыть share, выбрать канал (например «Копировать» / конкретное приложение).
2. Проверить в DebugView событие успеха (БТ §11.1 п.21).

**Ожидаемый результат:** При поддержке платформы фиксируется успешный share; если API недоступен — задокументировать ограничение.

**Заметки для автоматизации:** Часто `manual-only` из-за системного UI.

---

### TC-03 — Отмена share: нет ложного success

| Поле | Значение |
|------|----------|
| **Приоритет** | P1 |
| **Слой** | integration |
| **Покрывает** | AC-02 |
| **Тип** | negative |

**Шаги**

1. Открыть share и закрыть без выбора канала.
2. Проверить отсутствие события успешного share (или наличие только dismiss — по продуктовой схеме).

**Ожидаемый результат:** Воронка не искажается ложными success.
