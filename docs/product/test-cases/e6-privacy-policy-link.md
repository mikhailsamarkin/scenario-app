# Тест-кейсы: Ссылка на политику конфиденциальности в МП

## Обзор

- Цель: проверить работающий переход на согласованный URL политики из приложения (SR-PRIV-5) и доступность утверждённого текста по постоянному адресу, не только внутри APK (ED §2).
- Вне scope: CMP и баннеры согласия.

## Матрица трассировки AC → тест-кейсы

| AC    | TC-ID        | Кратко |
|-------|--------------|--------|
| AC-01 | TC-01, TC-02 | Пункт в МП открывает URL |
| AC-02 | TC-03        | Текст на веб-странице по стабильному URL |

## Тест-кейсы

### TC-01 — Переход из настроек / «О приложении» на политику

| Поле | Значение |
|------|----------|
| **Приоритет** | P0 |
| **Слой** | e2e |
| **Покрывает** | AC-01 |
| **Тип** | positive |

**Предусловия:** Известен согласованный URL политики.

**Шаги**

1. Открыть раздел с пунктом политики конфиденциальности.
2. Тап по пункту.
3. Проверить открытие внешнего браузера или WebView с корректным URL.

**Ожидаемый результат:** URL совпадает с юридически согласованным; страница загружается (SR-PRIV-5).

**Заметки для автоматизации:** Deep link тест; на iOS проверить SFSafariViewController.

---

### TC-02 — Негатив: недоступная сеть

| Поле | Значение |
|------|----------|
| **Приоритет** | P1 |
| **Слой** | e2e |
| **Покрывает** | AC-01 |
| **Тип** | negative |

**Шаги**

1. Включить авиарежим.
2. Попытаться открыть политику.

**Ожидаемый результат:** Понятная ошибка загрузки; без краша.

### TC-03 — GET страницы политики: статус 200 и контент

| Поле | Значение |
|------|----------|
| **Приоритет** | P0 |
| **Слой** | integration |
| **Покрывает** | AC-02 |
| **Тип** | positive |

**Шаги**

1. HTTP GET постоянного URL политики.
2. Проверить наличие ключевых разделов текста (хэш или маркер версии по процессу юр. команды).

**Ожидаемый результат:** Текст доступен по URL, не только внутри бинарника (ED §2).
