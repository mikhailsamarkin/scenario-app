# Тест-кейсы: Подписка на уведомления о новых сценариях

## Обзор

- Цель: проверить подписку на FCM topic после выдачи разрешения и отсутствие подписки без разрешения (A-8a, SR-PUSH-1).
- Вне scope: scheduler и дневная отправка (E3-03); при срезе без push — сторя не в обязательном MVP.

## Матрица трассировки AC → тест-кейсы

| AC    | TC-ID        | Кратко |
|-------|--------------|--------|
| AC-01 | TC-01        | После разрешения — subscribe на topic |
| AC-02 | TC-02        | Без разрешения — подписка не вызывается |

## Тест-кейсы

### TC-01 — Разрешение на уведомления: подписка на topic новых сценариев

| Поле | Значение |
|------|----------|
| **Приоритет** | P0 |
| **Слой** | integration |
| **Покрывает** | AC-01 |
| **Тип** | positive |

**Предусловия:** FCM настроен; тестовая сборка с логированием или Firebase DebugView.

**Тестовые данные:** Имя topic по СТ (например `new_scenarios`).

**Шаги**

1. Выдать разрешение на уведомления в системном диалоге.
2. Завершить flow подписки в приложении.
3. Проверить по логам/инструментам, что вызван `subscribeToTopic` с ожидаемым именем.

**Ожидаемый результат:** Клиент подписан на согласованный topic (A-8a).

**Заметки для автоматизации:** Мок FCM на уровне unit; e2e на реальном устройстве с логами.

---

### TC-02 — Разрешение не выдано: подписка не выполняется

| Поле | Значение |
|------|----------|
| **Приоритет** | P0 |
| **Слой** | integration |
| **Покрывает** | AC-02 |
| **Тип** | negative |

**Предусловия:** Свежая установка; при первом запросе выбрать «Запретить».

**Шаги**

1. Отклонить уведомления.
2. Использовать приложение в основном потоке.
3. Убедиться по логам, что `subscribeToTopic` не вызывается (или вызывается только после явного согласия в настройках — по реализации).

**Ожидаемый результат:** Нет подписки без разрешения; основной UX доступен.

**Заметки для автоматизации:** Проверка флага permission перед subscribe в unit-тесте.

---

### TC-03 — Повторный запрос после включения в настройках ОС

| Поле | Значение |
|------|----------|
| **Приоритет** | P1 |
| **Слой** | e2e |
| **Покрывает** | AC-01 |
| **Тип** | edge |

**Предусловия:** Сначала запрет, затем пользователь включил уведомления в настройках ОС и вернулся в приложение.

**Шаги**

1. Симулировать включение уведомлений извне.
2. Открыть приложение / экран настроек уведомлений в приложении.

**Ожидаемый результат:** При появлении разрешения выполняется подписка на topic.
