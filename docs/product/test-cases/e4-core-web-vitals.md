# Тест-кейсы: Core Web Vitals и производительность сайта

## Обзор

- Цель: проверить LCP, INP, CLS (или актуальный набор по СТ §13.1) на ключевых шаблонах и отлов регрессий в CI/Lighthouse (NFR-SR-5).
- Вне scope: минимальный релиз без сайта.

## Матрица трассировки AC → тест-кейсы

| AC    | TC-ID        | Кратко |
|-------|--------------|--------|
| AC-01 | TC-01, TC-02 | CWV в порогах §13.1 на выборке |

## Тест-кейсы

### TC-01 — Lighthouse / lab: страница сценария

| Поле | Значение |
|------|----------|
| **Приоритет** | P0 |
| **Слой** | integration |
| **Покрывает** | AC-01 |
| **Тип** | positive |

**Предусловия:** Стабильный staging URL; профиль сети и устройства согласованы.

**Шаги**

1. Запустить Lighthouse (или аналог) на странице сценария.
2. Сравнить LCP, INP, CLS с порогами СТ §13.1.

**Ожидаемый результат:** Метрики в пределах целевых порогов на согласованной выборке.

**Заметки для автоматизации:** `lhci autorun` в CI; пороги в `lighthouserc`.
