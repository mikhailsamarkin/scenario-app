# Тест-кейсы: Открытия сценария с разбивкой по source и scenario_id

## Обзор

- Цель: проверить, что событие открытия сценария содержит `scenario_id` и `source` из согласованного enum (FR-M-6); отдельные кейсы для home и push.
- Вне scope: источники E7 (group, past) до появления UI.

## Матрица трассировки AC → тест-кейсы

| AC    | TC-ID        | Кратко |
|-------|--------------|--------|
| AC-01 | TC-01        | source=home с витрины |
| AC-02 | TC-02        | source=push при E3 |

## Тест-кейсы

### TC-01 — Открытие сценария с главной витрины

| Поле | Значение |
|------|----------|
| **Приоритет** | P0 |
| **Слой** | integration |
| **Покрывает** | AC-01 |
| **Тип** | positive |

**Предусловия:** Fake Analytics; известный id сценария на витрине.

**Шаги**

1. Тап по карточке на главном экране.
2. Прочитать последнее событие открытия сценария.

**Ожидаемый результат:** `scenario_id` совпадает; `source` = `home` (или согласованный ключ из use-cases §6.2).

**Заметки для автоматизации:** Проверять enum `source` на compile-time.

---

### TC-02 — Открытие сценария из push

| Поле | Значение |
|------|----------|
| **Приоритет** | P0 |
| **Слой** | e2e |
| **Покрывает** | AC-02 |
| **Тип** | positive |

**Предусловия:** E3 включён; тестовый push с id сценария.

**Шаги**

1. Открыть приложение из уведомления (как E3-04).
2. Проверить событие открытия сценария.

**Ожидаемый результат:** `source` отражает push; `scenario_id` из payload.

### TC-03 — Негатив: произвольная строка в source недопустима
