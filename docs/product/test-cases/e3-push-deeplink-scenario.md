# Тест-кейсы: Deep link из push на экран сценария

## Обзор

- Цель: проверить переход по тапу на push к экрану сценария с корректным `scenarioId` и обработку холодного старта (A-13); корректная ошибка если сценарий недоступен.
- Вне scope: Universal Links с веба (E5), минимальный релиз без push.

## Матрица трассировки AC → тест-кейсы

| AC    | TC-ID        | Кратко |
|-------|--------------|--------|
| AC-01 | TC-01        | Тап → экран сценария |
| AC-02 | TC-02        | Холодный старт из уведомления |

## Тест-кейсы

### TC-01 — Тап по уведомлению открывает нужный сценарий

| Поле | Значение |
|------|----------|
| **Приоритет** | P0 |
| **Слой** | e2e |
| **Покрывает** | AC-01 |
| **Тип** | positive |

**Предусловия:** Тестовое FCM-сообщение с `scenarioId` существующего опубликованного сценария; приложение в фоне.

**Шаги**

1. Отправить тестовый push с payload по контракту СТ.
2. Тапнуть по уведомлению.
3. Проверить заголовок экрана / id сценария.

**Ожидаемый результат:** Открыт экран этого сценария (FR-M-4).

**Заметки для автоматизации:** Тестовые push через Firebase Console; стабильный `scenarioId`.

---

### TC-02 — Холодный старт: приложение не запущено

| Поле | Значение |
|------|----------|
| **Приоритет** | P0 |
| **Слой** | e2e |
| **Покрывает** | AC-02 |
| **Тип** | positive |

**Предусловия:** Приложение убито из памяти; затем тап по уведомлению.

**Шаги**

1. Принудительно закрыть приложение.
2. Тап по push.
3. Дождаться инициализации и проверить навигацию на сценарий.

**Ожидаемый результат:** После splash/инициализации открывается целевой сценарий (A-13).

**Заметки для автоматизации:** Увеличенные таймауты; флаки на медленных устройствах.

---

### TC-03 — Сценарий удалён или не опубликован: без утечки черновика

| Поле | Значение |
|------|----------|
| **Приоритет** | P1 |
| **Слой** | e2e |
| **Покрывает** | AC-01 |
| **Тип** | negative |

**Предусловия:** Payload с id несуществующего или снятого с публикации сценария.

**Шаги**

1. Открыть из такого push.
2. Проверить экран ошибки/пустого состояния.

**Ожидаемый результат:** Понятная ошибка; черновики не отображаются.
