# Тест-кейсы: Поделиться сценарием через системный share

## Обзор

- Цель: проверить открытие системного share sheet с URL и текстом, содержащими UTM, и соответствие заголовка/описания данным E1-04.
- Вне scope: Universal Links (E5-02), веб-fallback (E5-03).

## Матрица трассировки AC → тест-кейсы

| AC    | TC-ID        | Кратко |
|-------|--------------|--------|
| AC-01 | TC-01        | Share с UTM и текстом |
| AC-02 | TC-02        | Тексты из контента, не заглушка |

## Тест-кейсы

### TC-01 — Тап «Поделиться»: URL с UTM и текст сообщения

| Поле | Значение |
|------|----------|
| **Приоритет** | P0 |
| **Слой** | e2e |
| **Покрывает** | AC-01 |
| **Тип** | positive |

**Предусловия:** Экран сценария; домен scenario-games.ru (A-23); сеть доступна для формирования ссылки.

**Шаги**

1. Открыть сценарий.
2. Тап «Поделиться».
3. Выбрать канал (например копирование в буфер / Notes, если доступно).
4. Проверить, что в тексте есть HTTPS-URL с UTM-параметрами по СТ/БТ.

**Ожидаемый результат:** Сообщение содержит согласованный текст и URL с UTM (FR-M-7, A-18–A-19).

**Заметки для автоматизации:** На симуляторах share sheet ограничен — частично manual-only.

---

### TC-02 — Заголовок и описание из полей сценария

| Поле | Значение |
|------|----------|
| **Приоритет** | P0 |
| **Слой** | integration |
| **Покрывает** | AC-02 |
| **Тип** | positive |

**Предусловия:** В данных заданы уникальные title/description для шаринга.

**Шаги**

1. Сформировать share payload программно (unit) или перехватить до системного sheet.
2. Сравнить с данными из Firestore.

**Ожидаемый результат:** Нет захардкоженного «Lorem» или дефолта, отличного от контента.
