# Тест-кейсы: Создание игры с каруселью и валидацией полей

## Обзор

- Цель: проверить валидацию карусели (минимум один `teaser`, допустимые типы слайдов), enum-поля и доступность опубликованной игры для публичного read.
- Вне scope: отдельная веб-админка; вёрстка сайта (E4).

## Матрица трассировки AC → тест-кейсы

| AC    | TC-ID        | Кратко |
|-------|--------------|--------|
| AC-01 | TC-01, TC-02 | teaser обязателен; невалидная карусель отклонена |
| AC-02 | TC-03        | Только ключи из допустимого enum |
| AC-03 | TC-04        | Публичное чтение после публикации |

## Тест-кейсы

### TC-01 — Сохранение игры с валидной каруселью (есть слайд teaser)

| Поле | Значение |
|------|----------|
| **Приоритет** | P0 |
| **Слой** | integration |
| **Покрывает** | AC-01 |
| **Тип** | positive |

**Предусловия:** Скрипт импорта или пайплайн публикации; тестовое окружение Firebase.

**Тестовые данные:** JSON игры с каруселью: ≥1 слайд типа `teaser`, остальные типы из контракта, alt заданы где требуется.

**Шаги**

1. Выполнить импорт/сохранение игры с валидной каруселью.
2. Проверить отсутствие ошибок валидации и наличие записи в Firestore/Storage.

**Ожидаемый результат:** Игра сохранена; в данных присутствует минимум один слайд `teaser` с валидными типами.

**Заметки для автоматизации:** Фикстуры в `data/content`; прогон импорта в CI на dev-проекте.

---

### TC-02 — Отклонение карусели без слайда teaser

| Поле | Значение |
|------|----------|
| **Приоритет** | P0 |
| **Слой** | integration |
| **Покрывает** | AC-01 |
| **Тип** | negative |

**Предусловия:** Тот же канал импорта, что в TC-01.

**Тестовые данные:** Карусель только из типов, отличных от `teaser`.

**Шаги**

1. Попытаться сохранить/опубликовать игру без слайда `teaser`.
2. Зафиксировать ответ валидатора/скрипта.

**Ожидаемый результат:** Операция не завершается успешно; явная ошибка о требовании teaser (A-30).

**Заметки для автоматизации:** unit-тест валидатора + один e2e на импорт.

---

### TC-03 — Запрет неизвестных значений enum

| Поле | Значение |
|------|----------|
| **Приоритет** | P0 |
| **Слой** | unit |
| **Покрывает** | AC-02 |
| **Тип** | negative |

**Предусловия:** Известен список допустимых ключей enum по CR-4.1.

**Тестовые данные:** Поле enum со значением вне списка.

**Шаги**

1. Подать данные с недопустимым enum.
2. Проверить результат валидации.

**Ожидаемый результат:** Ошибка валидации; значение не записывается.

**Заметки для автоматизации:** Параметризованные тесты по реестру enum из одного источника правды.

---

### TC-04 — Публичный read опубликованной игры

| Поле | Значение |
|------|----------|
| **Приоритет** | P0 |
| **Слой** | integration |
| **Покрывает** | AC-03 |
| **Тип** | positive |

**Предусловия:** Игра опубликована в публичное представление; клиент с публичными правами.

**Тестовые данные:** ID опубликованной игры.

**Шаги**

1. Запросить публичный документ игры.
2. Сверить доступность полей карусели и медиа по правилам.

**Ожидаемый результат:** Данные читаются согласно правилам публичного read (A-29).

**Заметки для автоматизации:** Эмулятор правил + snapshot публичного JSON.
