# Тест-кейсы: Экран сценария: порядок блоков (обоснование → список игр)

## Обзор

- Цель: проверить визуальный порядок блока «почему эти игры» и списка игр, сохранение переносов строк в `whyTheseGames`.
- Вне scope: редактирование контента (E1), аналитика block_view (E6).

## Матрица трассировки AC → тест-кейсы

| AC    | TC-ID        | Кратко |
|-------|--------------|--------|
| AC-01 | TC-01        | Обоснование выше списка игр |
| AC-02 | TC-02        | Переносы \\n в тексте обоснования |

## Тест-кейсы

### TC-01 — Порядок: сначала whyTheseGames, ниже список игр

| Поле | Значение |
|------|----------|
| **Приоритет** | P0 |
| **Слой** | e2e |
| **Покрывает** | AC-01 |
| **Тип** | positive |

**Предусловия:** Сценарий с непустым `whyTheseGames` и ≥1 игрой.

**Шаги**

1. Открыть экран сценария.
2. Проскроллить сверху вниз.
3. Зафиксировать порядок: первый контентный блок — обоснование; ниже — список игр в порядке данных.

**Ожидаемый результат:** Блок обоснования визуально выше списка игр (FR-M-2).

**Заметки для автоматизации:** Сравнение `Rect` виджетов или порядок в семантическом дереве.

---

### TC-02 — Многострочный whyTheseGames отображается с переносами

| Поле | Значение |
|------|----------|
| **Приоритет** | P0 |
| **Слой** | widget |
| **Покрывает** | AC-02 |
| **Тип** | positive |

**Предусловия:** В данных текст с `\n` между абзацами.

**Тестовые данные:** Фикстура с известным количеством строк.

**Шаги**

1. Открыть экран сценария.
2. Проверить, что текст разбит на несколько визуальных строк/абзацев согласно `\n` (A-4a).

**Ожидаемый результат:** Переносы сохранены; нет схлопывания в одну строку без `\n`.

**Заметки для автоматизации:** Golden test на ширине экрана-эталона; учесть локализацию шрифта.
