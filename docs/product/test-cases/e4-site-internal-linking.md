# Тест-кейсы: Перелинковка сценариев и игр на сайте

## Обзор

- Цель: проверить рабочие внутренние ссылки между страницами сценария и игры на том же домене и отсутствие патологического N+1 чтений Firestore при билде (A-10d).
- Вне scope: минимальный релиз без сайта.

## Матрица трассировки AC → тест-кейсы

| AC    | TC-ID        | Кратко |
|-------|--------------|--------|
| AC-01 | TC-01        | Клик по игре → страница игры |
| AC-02 | TC-02        | Бюджет чтений на URL без N+1 |

## Тест-кейсы

### TC-01 — Со страницы сценария переход на страницу игры

| Поле | Значение |
|------|----------|
| **Приоритет** | P0 |
| **Слой** | e2e |
| **Покрывает** | AC-01 |
| **Тип** | positive |

**Предусловия:** Задеплоен staging сайт; сценарий с ≥1 игрой.

**Шаги**

1. Открыть страницу сценария.
2. Кликнуть по ссылке на игру из подборки.
3. Проверить URL, заголовок страницы игры.

**Ожидаемый результат:** Тот же домен; корректная страница игры (FR-W-2).

**Заметки для автоматизации:** Playwright; относительные пути.

---

### TC-02 — Обратные ссылки на сценарии с страницы игры

| Поле | Значение |
|------|----------|
| **Приоритет** | P1 |
| **Слой** | e2e |
| **Покрывает** | AC-01 |
| **Тип** | positive |

**Предусловия:** Игра входит в несколько сценариев или есть блок «сценарии с этой игрой» — по шаблону.

**Шаги**

1. Открыть страницу игры.
2. Перейти по ссылке на сценарий.
3. Проверить корректность целевой страницы.

**Ожидаемый результат:** Навигация без 404 в пределах опубликованного контента.

---

### TC-03 — Измерение чтений Firestore на URL при билде

| Поле | Значение |
|------|----------|
| **Приоритет** | P0 |
| **Слой** | integration |
| **Покрывает** | AC-02 |
| **Тип** | positive |

**Предусловия:** Включён счётчик/лог запросов к Firestore в пайплайне SSG (staging).

**Шаги**

1. Выполнить полный билд.
2. Для выборки URL сравнить число чтений на страницу с ориентиром A-10b/A-10d.

**Ожидаемый результат:** Нет линейного роста запросов на каждый внутренний объект (без N+1).

**Заметки для автоматизации:** Логи в CI; порог регрессии.
