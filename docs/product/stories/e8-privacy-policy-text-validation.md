# Валидация текста политики конфиденциальности тех. лидом

## Ценность

Текст политики должен описывать фактический состав SDK и категории данных по актуальной документации Google (**SR-PRIV-5**, **ED §2**). Юридически утверждённого текста нет — берём стандартный из похожих МП/сайтов и валидируем тех. лидом.

## Контекст и трассировка

| ID | Документ | Как используется в этой стори |
|----|----------|-------------------------------|
| SR-PRIV-5 | СТ | Текст описывает Firebase/GA4 по категориям данных |
| ED §2 | ED | Роль URL и текста политики |

## Детали поведения

- Взять стандартный текст политики из похожих МП/сайтов.
- Тех. лид валидирует соответствие фактическому составу SDK (Firebase, GA4, Supabase, share_plus, app_links).
- Утверждённый текст публикуется на странице `/privacy` (**US-E8-02**).

## Вне scope

- Реализация страницы — **US-E8-02**.
- Юридическая экспертиза (если потребуется отдельно).

## Критерии приёмки (AC)

- **AC-01** *(СТ SR-PRIV-5)*  
  - Given утверждённый текст  
  - When публикация  
  - Then текст описывает фактический состав SDK и доступен по URL.

## Зависимости и блокеры

- Решение тех. лида по тексту.

## Открытые вопросы

- Нет.

## Примечания для downstream

- Не путать с настройками GA4; политика описывает фактический состав SDK (**ED §2**).
