# Ссылка на политику конфиденциальности в МП

## Ценность

Пользователь может открыть согласованную политику по постоянному URL; ожидания сторов и **SR-PRIV-5** выполняются (**engineering-decisions** §2).

## Контекст и трассировка

| ID | Документ | Как используется в этой стори |
|----|----------|-------------------------------|
| SR-PRIV-5 | СТ | Ссылка из МП и доступность текста |
| ED §2 | ED | Роль URL и текста политики |

## Детали поведения

- В приложении есть вход к политике (например настройки / экран о приложении).
- Ссылка открывается во внешнем браузере или WebView по решению UX; URL стабилен.
- Текст политики согласован юридически — вне инженерного объёма, но **блокер релиза** продуктово-юридический (**ED** §2).

## Вне scope

- CMP и баннеры согласия — **вне СТ** (**use-cases** §6.4).

## Критерии приёмки (AC)

- **AC-01** *(СТ SR-PRIV-5)*  
  - Given пользователь ищет политику  
  - When открывает пункт в МП  
  - Then переход на согласованный URL политики работает.

- **AC-02** *(ED §2)*  
  - Given юридически утверждённый текст  
  - When публикация  
  - Then текст доступен по постоянному адресу (не «только внутри APK» как единственный вариант).

## Зависимости и блокеры

- Готовый URL и текст от юридической стороны.

## Открытые вопросы

- Нет.

## Примечания для downstream

- Не путать с настройками GA4; политика описывает фактический состав SDK (**ED** §2).
