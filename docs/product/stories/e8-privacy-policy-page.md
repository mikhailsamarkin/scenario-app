# Страница политики конфиденциальности на сайте

## Ценность

МП (US-E6-04) открывает политику по постоянному URL `https://scenario-games.ru/privacy`. Эта стори реализует саму страницу на сайте (SSG Next.js), чтобы текст был доступен по адресу, а не только внутри APK (**SR-PRIV-5**, **ED §2**).

## Контекст и трассировка

| ID | Документ | Как используется в этой стори |
|----|----------|-------------------------------|
| SR-PRIV-5 | СТ | Политика доступна из МП и с сайта |
| ED §2 | ED | Роль URL и текста политики |

## Детали поведения

- Страница `/privacy` на сайте `scenario-games.ru` (SSG Next.js).
- Текст политики — из **US-E8-03** (валидация тех. лидом); до утверждения — placeholder.
- URL стабилен и совпадает с константой в МП (**US-E6-04**).

## Вне scope

- Текст политики (юридический) — **US-E8-03**.
- Вход из МП — **US-E6-04** (реализован).

## Критерии приёмки (AC)

- **AC-01** *(СТ SR-PRIV-5)*  
  - Given пользователь открывает `https://scenario-games.ru/privacy`  
  - When GET  
  - Then страница возвращает 200 и содержит текст политики.

- **AC-02**  
  - Given URL из МП  
  - When переход  
  - Then адрес совпадает с константой в МП (**US-E6-04**).

## Зависимости и блокеры

- Текст политики — **US-E8-03**.
- Домен `scenario-games.ru` и SSG-сайт (**E4**).

## Открытые вопросы

- Нет.

## Примечания для downstream

- Согласовать с **US-E8-03** (текст) и **US-E6-04** (URL в МП).
