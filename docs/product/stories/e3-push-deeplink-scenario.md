# Deep link из push на экран сценария

## Ценность

Тап по уведомлению ведёт прямо к релевантному сценарию без лишних шагов (**FR-M-4**, **UC-04**).

## Контекст и трассировка

| ID | Документ | Как используется в этой стори |
|----|----------|-------------------------------|
| FR-M-4 | БТ | Открытие сценария из уведомления |
| A-13 | СТ | Deep link / маршрутизация в приложении |
| UC-04 | use-cases | Тап → deep link на сценарий |

## Детали поведения

- Payload FCM содержит идентификатор сценария (`scenarioId` или по контракту **СТ**).
- Приложение обрабатывает открытие и навигацию на экран сценария.
- Сценарий доступен в публичных данных; если не найден — корректная ошибка (**без** утечки черновиков).

## Вне scope

- Universal Links с веба (**E5**).
- **Минимальный первый релиз без push** — приёмка при включении E3.

## Критерии приёмки (AC)

- **AC-01** *(БТ FR-M-4)*  
  - Given пользователь получил push о новом сценарии  
  - When тап по уведомлению  
  - Then открывается экран этого сценария.

- **AC-02** *(СТ A-13)*  
  - Given холодный старт из уведомления  
  - When приложение инициализируется  
  - Then маршрут восстанавливается к сценарию.

## Зависимости и блокеры

- Навигация **E2**.
- Корректный payload от **US-E3-03**.
