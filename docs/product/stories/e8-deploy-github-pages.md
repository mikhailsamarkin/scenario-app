# Деплой сайта на GitHub Pages

## Ценность

Билд-пайплайн (**US-E4-04**) собирает статический сайт в `out/`, но не публикует его. Эта стори выкладывает результат сборки на GitHub Pages, чтобы сайт был доступен по постоянному URL (**ED-3**, **A-26a**).

## Контекст и трассировка

| ID | Документ | Как используется в этой стори |
|----|----------|-------------------------------|
| ED-3 | ED | Хостинг сайта |
| A-26a | СТ | SSG Next.js, репозиторий scenario-site |
| US-E4-04 | Стори | Билд-пайплайн (сборка в `out/`) |

## Детали поведения

- После успешной сборки (`npm run build`, `output: export`) артефакт `out/` загружается на GitHub Pages.
- Сайт доступен по URL `https://<user>.github.io/scenario-site/`.
- Деплой — часть CI-пайплайна (после сборки в `build.yml`).

## Вне scope

- Сборка SSG — **US-E4-04** (реализована).
- Core Web Vitals — **US-E4-05** (реализована).
- Прод-домен `scenario-games.ru` — отдельная задача (DNS/SSL).

## Критерии приёмки (AC)

- **AC-01** *(СТ A-26a, ED-3)*  
  - Given успешная сборка  
  - When workflow завершается  
  - Then сайт доступен по URL GitHub Pages.

- **AC-02**  
  - Given обновление контента  
  - When запущен билд  
  - Then опубликованная версия обновляется.

## Зависимости и блокеры

- **US-E4-04** — билд-пайплайн (реализован).
- Включённый GitHub Pages в настройках репозитория.

## Открытые вопросы

- Нет.

## Примечания для downstream

- Координация с **US-E8-01** (домен) и **US-E8-02** (страница политики) при переходе на прод-домен.
