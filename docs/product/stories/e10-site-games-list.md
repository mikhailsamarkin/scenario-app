# Страница списка игр

## Ценность

Сейчас страницы списка игр нет вовсе (`games/` содержит только деталку `[slug]`). Эта стори добавляет `/games` со списком опубликованных игр из публичного агрегата, той же механикой, что в МП (**A-10/A-12**).

## Контекст и трассировка

| ID | Документ | Как используется в этой стори |
|----|----------|-------------------------------|
| FR-W-2 | БТ | Навигация по контенту на сайте |
| A-10 / A-12 | СТ | Чтение публичных агрегатов контракта |
| A-10b | СТ | Бюджет чтений при билде |
| SR-SEO-1 | СТ | SEO-требования |
| ED-14 | ED | Supabase-медиа |

## Детали поведения

- Страница читает `sitemap_public/main` через `getSitemap` (`src/lib/contract/repository.ts`) → `gameEntries` (slug + id).
- Для каждой игры — карточка со ссылкой на `/games/[slug]`.
- Заголовки/превью — из `game_public/{id}` (без N+1 — см. ниже) или из `home_feed/main.carousel` (если игра в карусели).
- Медиа (imageRef) — через `SupabaseImage` / `supabasePublicUrl` (**ED-14**).
- Окружение — `NEXT_PUBLIC_ENV` (dev/prod), механика как в МП (**A-26a**).
- SSG-рендер на сервере — контент доступен для индексации (**SR-SEO-1**).

## Вне scope

- Деталки игры — **US-E4-01** (реализованы).

## Критерии приёмки (AC)

- **AC-01** *(БТ FR-W-2, СТ A-10/A-12)*
  - Given опубликованные игры
  - When открыт `/games`
  - Then отображается список всех опубликованных игр, соответствующий env.

- **AC-02** *(СТ A-10b)*
  - Given билд списка
  - When измеряется число чтений
  - Then 1–2 чтения на URL (без N+1).

- **AC-03** *(СТ SR-SEO-1)*
  - Given список
  - When собран
  - Then контент доступен для индексации.

## Зависимости и блокеры

- Агрегаты **E0** (реализованы).
- Деталки **US-E4-01** (реализованы).

## Открытые вопросы

- Откуда брать заголовки/превью карточек: из `sitemap_public` (slug) или подгружать `game_public`? Для соблюдения A-10b — предпочтительно из `home_feed/main.carousel` (уже содержит caption/alt/imageRef).

## Примечания для downstream

- Не читать `game_public/{id}` для каждого элемента (N+1). Использовать `sitemap_public/main` + при необходимости `home_feed/main.carousel`.
- Добавить ссылку на `/games` в навигацию (`layout.tsx`).
