# Веб-fallback: OG и сохранение UTM

## Ценность

Получатель без приложения видит ту же подборку в браузере с корректным превью; UTM не теряются при редиректах (**FR-W-4**, **A-25**).

## Контекст и трассировка

| ID | Документ | Как используется в этой стори |
|----|----------|-------------------------------|
| FR-W-4 | БТ | Веб-страница по ссылке |
| A-25 | СТ | UTM не сбрасываются редиректом |

## Детали поведения

- Страница сценария на сайте отдаёт OG-теги из данных (**US-E1-04**, **E4**).
- Цепочки редиректов сохраняют query-параметры UTM (**A-25**).
- CTA в МП — **US-E4-03**.

## Вне scope

- **Минимальный первый релиз без сайта** — вместе с E4.

## Критерии приёмки (AC)

- **AC-01** *(БТ FR-W-4)*  
  - Given пользователь без МП  
  - When открывает share-ссылку  
  - Then загружается веб-страница сценария с корректным контентом и OG.

- **AC-02** *(СТ A-25)*  
  - Given ссылка с UTM  
  - When выполняется редирект (если есть)  
  - Then UTM сохраняются в финальном URL.

## Зависимости и блокеры

- **E4**, домен и SSL (**A-23**).
