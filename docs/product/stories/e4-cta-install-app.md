# CTA установки мобильного приложения

## Ценность

Органический трафик конвертируется в установки МП через явные призывы (**FR-W-3**, **BR-5**).

## Контекст и трассировка

| ID | Документ | Как используется в этой стори |
|----|----------|-------------------------------|
| FR-W-3 | БТ | CTA в шапке/подвале и на контентных страницах |

## Детали поведения

- На сайте присутствуют ссылки в сторы (iOS/Android) в шапке, подвале и на страницах сценария/игры.
- Визуальная заметность согласуется с дизайном; клики учитываются в метриках (**use-cases** §6.2 п.24–25).

## Вне scope

- **Минимальный первый релиз без сайта.**

- Атрибуция установок через MMP — вне этой стори, если не в **СТ**.

## Критерии приёмки (AC)

- **AC-01** *(БТ FR-W-3)*  
  - Given любая контентная страница сценария/игры  
  - When пользователь просматривает страницу  
  - Then доступен заметный CTA установки МП (шапка/подвал/блок — по макету).

- **AC-02**  
  - Given главная страница сайта  
  - When открыта  
  - Then CTA присутствует в шапке и/или подвале.

## Зависимости и блокеры

- Нет.
