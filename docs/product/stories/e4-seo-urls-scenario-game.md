# ЧПУ и метаданные страниц сценария и игры

## Ценность

Отдельные URL и метаданные поддерживают органический трафик и соответствие ожиданиям поиска (**FR-W-2**, **BR-5**, **SR-SEO-1**).

## Контекст и трассировка

| ID | Документ | Как используется в этой стори |
|----|----------|-------------------------------|
| FR-W-2 | БТ | Страницы сценария/игры, метаданные |
| SR-SEO-1 | СТ | SEO-требования |
| A-26a | СТ | Структура URL/публикации сайта |
| ED-10 | СТ | Rebuild сайта по триггеру |
| UC-03 | use-cases | Органика |

## Детали поведения

- SSG генерирует маршруты для сценария и игры с ЧПУ (slug из данных **ED-8** / **E1**).
- `<title>` и description берутся из полей контента (**US-E1-04**).
- Соответствие **SR-SEO-1**.

## Вне scope

- **Минимальный первый релиз без сайта** (**use-cases** §6.1) — сторя вне обязательного MVP; планируется с E4.

## Критерии приёмки (AC)

- **AC-01** *(БТ FR-W-2, СТ SR-SEO-1)*  
  - Given опубликованные сценарий и игра  
  - When билд SSG  
  - Then существуют отдельные URL с корректными title/description.

- **AC-02**  
  - Given поисковый робот  
  - When запрашивает страницу  
  - Then контент доступен для индексации согласно **SR-SEO-1**.
