# Предсказуемый билд SSG: бюджет запросов к Firestore

## Ценность

Статическая сборка не должна взрывать квоты и время CI; ориентир — 1–2 чтения на URL при агрегатах (**СТ A-10b**).

## Контекст и трассировка

| ID | Документ | Как используется в этой стори |
|----|----------|-------------------------------|
| A-10b | СТ | Бюджет чтений при билде |
| ED-10 | ED | Полный rebuild по ручному триггеру |

## Детали поведения

- Пайплайн сборки Next.js читает опубликованные данные через агрегаты (**A-10**, **E0**).
- Количество запросов к Firestore на сгенерированный URL укладывается в ориентир **A-10b**.
- Триггер билда — **ED-10** (workflow_dispatch).

## Вне scope

- ISR по расписанию (**ED-10**).

## Критерии приёмки (AC)

- **AC-01** *(СТ A-10b)*  
  - Given полный список публичных URL  
  - When выполняется билд  
  - Then среднее/пиковое число чтений на URL не превышает согласованный ориентир (зафиксировать измерение в CI).

- **AC-02** *(ED-10)*  
  - Given обновление контента  
  - When команда запускает workflow  
  - Then выполняется полный rebuild согласованным способом.

## Зависимости и блокеры

- Агрегаты и индексы **E0**.

## Открытые вопросы

- Точный лимит времени CI — зафиксировать в команде.

## Примечания для downstream

- Логировать метрики билда для регрессий.
