# Экран сценария: порядок блоков (обоснование → список игр)

## Ценность

Правильный порядок блоков снимает когнитивную нагрузку: сначала «почему», затем подборка (**FR-M-2**, версия 0.9+ в **БТ**).

## Контекст и трассировка

| ID | Документ | Как используется в этой стори |
|----|----------|-------------------------------|
| FR-M-2 | БТ | Порядок блоков на экране сценария |
| A-12, A-15 | СТ | Контракт и представление экрана в МП |

## Детали поведения

- Блок «почему эти игры подходят» (`whyTheseGames`) отображается выше списка игр.
- Список игр следует согласно порядку из данных сценария.
- Тексты — plain text с переносами (**СТ A-4a**) для `whyTheseGames`.

## Вне scope

- Редактирование контента (E1).
- Аналитика block_view (E6) — отдельная сторя.

## Критерии приёмки (AC)

- **AC-01** *(БТ FR-M-2)*  
  - Given открыт экран сценария  
  - When пользователь скроллит сверху вниз  
  - Then сначала виден блок обоснования, ниже — список игр.

- **AC-02** *(СТ A-4a)*  
  - Given текст `whyTheseGames` с `\n`  
  - When отображается  
  - Then переносы строк сохраняются визуально.

## Зависимости и блокеры

- Опубликованный сценарий с привязанными играми (**E1**).

## Открытые вопросы

- Нет.

## Примечания для downstream
