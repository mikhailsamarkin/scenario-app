# UI-редизайн экранов по Figma-макетам

## Ценность

Экраны МП (онбординг, home, сценарий, игра) приводятся к утверждённому дизайну из Figma: брендированная тема, hero-блоки, карточки, чипсы. Функциональность и AC существующих сторей (E2/E3) сохраняются — меняется только presentation-слой (**FR-M-1/2/3**).

## Контекст и трассировка

| ID | Документ | Как используется в этой стори |
|----|----------|-------------------------------|
| FR-M-1 | БТ | Главный экран и доступ к сценариям |
| FR-M-2 | БТ | Экран сценария |
| FR-M-3 | БТ | Экран игры |
| docs/figma/ | Figma | Макеты и разбор (README, screens/, design-tokens.md) |

## Детали поведения

- **Дизайн-система**: палитра и типографика из `docs/figma/design-tokens.md`; общие виджеты (hero-блок, капс-заголовок, точки-индикаторы, карточки, кнопки).
- **Онбординг**: 3 шага вместо 4 (третий — push), тёмная тема, новые тексты, точки-индикаторы, место под иллюстрации.
- **Home**: брендированная шапка, лента витрины («Редакторский выбор»), секции по категориям (= группы смысла, E7).
- **Сценарий**: hero-фото с категорией, капс-заголовки, чипсы характеристик, счётчик игр.
- **Игра**: hero-карусель, сетка 2×2 характеристик, бейдж caption.

## Вне scope

- Изменение контракта данных (кроме категории = группы смысла — **US-E7-01**).
- Новая функциональность (кроме presentation-слоя).

## Критерии приёмки (AC)

- **AC-01** *(FR-M-1/2/3)*  
  - Given экраны МП  
  - When открыты  
  - Then соответствуют макетам Figma (тема, hero, карточки, чипсы).

- **AC-02**  
  - Given редизайн  
  - When регресс  
  - Then функциональные AC существующих сторей (E2/E3) сохранены.

## Зависимости и блокеры

- **US-E7-01** — группы смысла (категории) для home и сценария.
- Точные токены (hex, гарнитуры) — снять Dev Mode'ом из Figma.
- Ассеты (иллюстрации онбординга) — источник/формат.
