# Сайт: контентные страницы из Firebase/Supabase по env (как в МП)

## Ценность

Сейчас сайт (scenario-site) — SSG-заглушка: главная (`/`) и списки `/scenarios` и `/games` не читают данные, работают только деталки сценария и игры (US-E4-01). Этот эпик доводит три ключевые страницы до состояния, когда они получают контент из публичных агрегатов Firestore и медиа из Supabase Storage — **той же механикой, что и МП** (единый контракт `*_public` / `home_feed` / `sitemap_public`, **A-10/A-12**), с выбором окружения dev/prod через `NEXT_PUBLIC_ENV` (**A-26a**).

## Механика (общая для всех стори эпика)

- **Данные** — только публичные коллекции Firestore: `home_feed/main`, `sitemap_public/main`, `scenario_public/{id}`, `game_public/{id}`, `semantic_groups_public/{id}` (контракт **SP-E0-01**, репозиторий `src/lib/contract/repository.ts`). Источник правды (`games`, `scenarios`, …) клиенту недоступен (**A-38**).
- **Медиа** — Supabase Storage (бакет `games`), публичный URL через `supabasePublicUrl` (**ED-14**, компонент `SupabaseImage`).
- **Окружение** — `NEXT_PUBLIC_ENV` (dev/prod) выбирает Firebase-проект и Supabase URL/ключ (**A-26a**, `src/lib/firebase.ts`, `src/lib/supabase.ts`). Механика идентична `AppConfig` в МП.
- **SSG** — страницы собираются на сервере (Next.js `output: export`), контент доступен для индексации (**SR-SEO-1**); чтение без N+1 (**A-10b/A-10d**).

## Вне scope

- Деталки сценария/игры — уже реализованы (**US-E4-01**); в этом эпике только доработка при необходимости.
- Перелинковка — **US-E4-02** (частично затрагивается списками).
- Прод-домен `scenario-games.ru` — **US-E8-01**.
- Аналитика сайта — вне этого эпика.

## Критерии приёмки (AC)

- **AC-01** *(БТ FR-W-1/2, СТ A-10/A-12)*
  - Given опубликованные данные в dev и prod
  - When открыты главная, список сценариев, список игр
  - Then страницы показывают контент из публичных агрегатов Firestore и медиа из Supabase, соответствующий выбранному env.

- **AC-02** *(СТ A-10b/A-10d)*
  - Given билд SSG
  - When измеряется число чтений Firestore на URL
  - Then укладывается в ориентир (без патологического N+1).

- **AC-03** *(СТ SR-SEO-1)*
  - Given страницы
  - When собраны
  - Then контент доступен для индексации (SSG-рендер на сервере).

## Примечания для downstream

- Списки должны ссылаться на существующие деталки (`/scenarios/[slug]`, `/games/[slug]`).
- Соблюдать бюджет чтений: списки читают один агрегат (`sitemap_public/main` или `home_feed/main`), без подгрузки каждого документа.
