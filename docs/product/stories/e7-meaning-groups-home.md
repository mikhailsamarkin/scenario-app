# Группы смысла на главном экране

## Ценность

Группы ускоряют навигацию по типам ситуаций без перегрузки плоской витрины (**БТ §7.1**, **FR-M-1**).

## Контекст и трассировка

| ID | Документ | Как используется в этой стори |
|----|----------|-------------------------------|
| БТ §7.1 | БТ | Группы задаются контентом на бэкенде |
| FR-M-1 | БТ | Главный экран и доступ к сценариям |

## Детали поведения

- На главном экране отображаются группы смысла, конфигурируемые данными (не хардкодом в клиенте).
- Переход в группу показывает релевантные сценарии по правилам контента.

## Вне scope

- **Минимальный первый релиз без групп** (**use-cases** шапка и §6.1).

- Остальная витрина **US-E2-01** без групп.

## Критерии приёмки (AC)

- **AC-01** *(БТ §7.1)*  
  - Given в данных заданы группы  
  - When пользователь открывает главный экран  
  - Then видны группы и их состав соответствует серверу.

- **AC-02**  
  - Given тап по группе  
  - When экран группы открыт  
  - Then список сценариев соответствует контентной конфигурации.

## Зависимости и блокеры

- Расширение схемы **E0** под группы.
- Аналитика «group» — **US-E6-02** при включении.

## Открытые вопросы

- Нет.

## Примечания для downstream

- Не дублировать логику витрины «Сценарии прошлого» — см. **US-E7-02**.
