# Главный экран: витрина сценариев

## Ценность

Витрина реализует JTBD «ситуация → игры»: пользователь выбирает релевантный сценарий с главного экрана (**FR-M-1**, **UJ-1**).

## Контекст и трассировка

| ID | Документ | Как используется в этой стори |
|----|----------|-------------------------------|
| FR-M-1 | БТ | Состав и порядок сценариев на главном экране |
| A-12 | СТ | Чтение контракта в МП |
| UC-01 | use-cases | Поток витрина → сценарий |

## Детали поведения

- Главный экран загружает список сценариев из публичного агрегата/контракта (**A-12**).
- Для каждого элемента: название, при наличии — подзаголовок; порядок как на сервере (**FR-M-1**).
- Переход на экран сценария по тапу.

## Вне scope

- Группы смысла (E7).
- Push-реактивация (E3).

## Критерии приёмки (AC)

- **AC-01** *(БТ FR-M-1)*  
  - Given опубликованная витрина  
  - When пользователь открывает главный экран  
  - Then отображаются сценарии в порядке и составе с сервера.

- **AC-02**  
  - Given элемент витрины  
  - When отображается  
  - Then видны название и опциональный подзаголовок из данных.

## Зависимости и блокеры

- **E0/E1:** `home_feed` или эквивалент и опубликованные сценарии.
