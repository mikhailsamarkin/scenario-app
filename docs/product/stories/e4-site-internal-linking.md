# Перелинковка сценариев и игр на сайте

## Ценность

Внутренние ссылки удерживают пользователя в воронке контента и снижают зависимость от внешнего поиска (**FR-W-2**).

## Контекст и трассировка

| ID | Документ | Как используется в этой стори |
|----|----------|-------------------------------|
| FR-W-2 | БТ | Навигация по контенту на сайте |
| A-10d | СТ | Перелинковка без N+1 при билде |

## Детали поведения

- Страницы сценария содержат ссылки на игры подборки; страница игры — на связанные сценарии или обратно — по данным и шаблону.
- При статической генерации данные подгружаются агрегатами, без N+1 запросов на каждый URL (**A-10d**).

## Вне scope

- **Минимальный первый релиз без сайта.**

## Критерии приёмки (AC)

- **AC-01** *(БТ FR-W-2)*  
  - Given страница сценария  
  - When пользователь кликает по игре  
  - Then открывается страница игры с тем же доменом и структурой.

- **AC-02** *(СТ A-10d)*  
  - Given билд всех страниц  
  - When измеряется число чтений Firestore на URL  
  - Then укладывается в ориентир **A-10b** / **A-10d** (без патологического N+1).
