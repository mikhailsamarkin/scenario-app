# Core Web Vitals и производительность сайта

## Ценность

Соответствие **NFR** по скорости страниц поддерживает SEO и UX (**NFR-SR-5**, **СТ §13.1**).

## Контекст и трассировка

| ID | Документ | Как используется в этой стори |
|----|----------|-------------------------------|
| NFR-SR-5 | БТ / СТ | Производительность веба |
| СТ §13.1 | СТ | Целевые пороги CWV |

## Детали поведения

- Измерение LCP, INP, CLS (или актуального набора **§13.1**) на ключевых шаблонах.
- Регрессии ловятся в CI/Lighthouse или аналоге по политике команды.

## Вне scope

- **Минимальный первый релиз без сайта.**

## Критерии приёмки (AC)

- **AC-01** *(СТ §13.1, NFR-SR-5)*  
  - Given страницы сценария и игры  
  - When измеряются CWV  
  - Then метрики укладываются в целевые пороги из **СТ §13.1** (на согласованной выборке устройств/сетей).

## Зависимости и блокеры
