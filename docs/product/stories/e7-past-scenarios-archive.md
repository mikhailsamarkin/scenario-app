# «Сценарии прошлого» для снятых с витрины подборок

## Ценность

Сезонные и архивные подборки остаются доступными без конкуренции с актуальной витриной (**CR-3**, **FR-M-1**).

## Контекст и трассировка

| ID | Документ | Как используется в этой стори |
|----|----------|-------------------------------|
| CR-3 | БТ | Раздел «прошлое», не конкурирует с витриной |
| FR-M-1 | БТ | Навигация к сценариям |

## Детали поведения

- Сценарии с признаком «снят с витрины» попадают в раздел «Сценарии прошлого» (или эквивалент по копирайту).
- Актуальная витрина не дублирует эти сценарии в основном списке (**CR-3**).
- Данные задаются контентом/флагами на бэкенде.

## Вне scope

- **Минимальный первый релиз** без этого раздела (**use-cases** шапка).

## Критерии приёмки (AC)

- **AC-01** *(БТ CR-3)*  
  - Given сценарий снят с витрины  
  - When пользователь открывает раздел «Сценарии прошлого»  
  - Then сценарий доступен там и не отображается как активная витринная карточка.

- **AC-02**  
  - Given сценарий на витрине  
  - When пользователь смотрит только «прошлое»  
  - Then дублирования с главной витриной нет.
