# Очередь уведомлений при первой публикации сценария

## Ценность

Дневной push о новинке опирается на триггер публикации; правки только состава игр не должны порождать лишние уведомления (**СТ A-31, A-33**, **FR-B-4**, **FR-M-4**).

## Контекст и трассировка

| ID | Документ | Как используется в этой стори |
|----|----------|-------------------------------|
| FR-B-4, FR-M-4 | БТ | События публикации и доставка в МП |
| A-31, A-33 | СТ | Логика очереди и исключений |
| ED-11 | ED | Тексты push могут храниться в Firestore/конфиге |

## Детали поведения

- При **первой** публикации сценария создаётся запись/событие в очереди на дневную рассылку (**A-31**).
- Изменение только списка игр без повторной «новой публикации» не ставит дубликат в очередь (по **A-33** и формулировке **use-cases**).
- При **отложенном push** в продукте: инфраструктура очереди готовится совместно с **E3** или как backend-only без FCM до включения рассылки (**use-cases** US-E1-05).

## Вне scope

- **Минимальный первый релиз без push** (**use-cases** шапка): приёмка может быть «очередь и триггеры реализованы / зафлажены», FCM и scheduler — при включении E3.

- Тексты и тон пуша — организационно (**use-cases** §6.4); технически — **ED-11**.

## Критерии приёмки (AC)

- **AC-01** *(СТ A-31)*  
  - Given первая публикация сценария  
  - When публикация завершена  
  - Then в очереди уведомлений появляется соответствующее событие.

- **AC-02** *(СТ A-33, продуктовая логика use-cases)*  
  - Given сценарий уже был опубликован  
  - When меняется только порядок/состав игр  
  - Then новое событие «новинка дня» для push не создаётся.

- **AC-03** *(срез без push)*  
  - Given релиз без FCM  
  - When очередь заполняется  
  - Then данные готовы к подключению E3 без миграции формата.

## Зависимости и блокеры

- Cloud Functions / Scheduler при полном E3 (**use-cases** US-E3-03).
- Согласованность с **ED-11** для payload.

## Открытые вопросы

- Точная детализация «первой публикации» vs «републикации» в коде — уточнить при реализации триггеров (без противоречия **A-33**).

## Примечания для downstream

- Связка с **US-E3-02–04** при включении push.
