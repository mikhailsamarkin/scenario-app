# Замена placeholder-ссылок на сторы в CTA

## Ценность

CTA установки МП (US-E4-03) использует placeholder-ссылки на сторы. Эта стори заменяет их реальными идентификаторами приложений, чтобы CTA вёл на рабочие страницы сторов (**FR-W-3**).

## Контекст и трассировка

| ID | Документ | Как используется в этой стори |
|----|----------|-------------------------------|
| FR-W-3 | БТ | CTA установки МП |
| SP-E4-03 | Спека | Компонент InstallCta, ссылки на сторы |

## Детали поведения

- В `scenario-site/src/lib/stores.ts` заменить placeholder-URL на реальные ссылки iOS/Android.
- Идентификаторы приложений (app id / package name) — из сторов после публикации.

## Вне scope

- Компонент CTA и его размещение — **US-E4-03** (реализовано).

## Критерии приёмки (AC)

- **AC-01** *(БТ FR-W-3)*  
  - Given CTA установки  
  - When клик  
  - Then переход на реальную страницу стора (iOS/Android).

## Зависимости и блокеры

- Публикация приложения в Apple App Store / Google Play (идентификаторы).

## Открытые вопросы

- Нет.

## Примечания для downstream

- Согласовать с релизом МП (идентификаторы приложений).
