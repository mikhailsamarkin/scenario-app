# Главная страница сайта: витрина, группы, карусель

## Ценность

Сейчас главная (`src/app/page.tsx`) — заглушка «Hello World {env}` с одной ссылкой. Эта стори превращает её в полноценную точку входа: витрина сценариев, группы смысла и карусель игр — те же данные и механика, что у главного экрана МП (**US-E2-01**, **US-E7-01**), но для веба (**FR-W-1**).

## Контекст и трассировка

| ID | Документ | Как используется в этой стори |
|----|----------|-------------------------------|
| FR-W-1 | БТ | Главная страница сайта |
| A-10 / A-12 | СТ | Чтение публичных агрегатов контракта |
| A-10b | СТ | Бюджет чтений при билде |
| SR-SEO-1 | СТ | SEO-требования |
| ED-14 | ED | Supabase-медиа |

## Детали поведения

- Главная читает `home_feed/main` через `getHomeFeed` (`src/lib/contract/repository.ts`).
- **Витрина** (`vitrine`): карточки сценариев (title, subtitle, imageRef) со ссылками на `/scenarios/[slug]`.
- **Группы смысла** (`groups`): секции со ссылками на деталки групп (или на список сценариев, если деталки групп не реализованы — см. US-E10-02).
- **Карусель** (`carousel`): слайды игр (imageRef, caption, alt) со ссылками на `/games/[slug]` (slug из `sitemap_public/main`).
- Медиа — через `SupabaseImage` / `supabasePublicUrl` (**ED-14**).
- Окружение — `NEXT_PUBLIC_ENV` (dev/prod), механика как в МП (**A-26a**).
- SSG-рендер на сервере — контент доступен для индексации (**SR-SEO-1**).

## Вне scope

- Деталки сценария/игры — **US-E4-01** (реализованы).
- Деталки групп смысла — отдельная задача (если не реализованы).

## Критерии приёмки (AC)

- **AC-01** *(БТ FR-W-1, СТ A-10/A-12)*
  - Given опубликованные `home_feed/main` и `sitemap_public/main`
  - When открыта главная
  - Then отображаются витрина, группы и карусель из данных, соответствующие env.

- **AC-02** *(СТ A-10b)*
  - Given билд главной
  - When измеряется число чтений
  - Then 1–2 чтения на URL (без N+1).

- **AC-03** *(СТ SR-SEO-1)*
  - Given главная
  - When собрана
  - Then контент доступен для индексации.
