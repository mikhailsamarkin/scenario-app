# Страница списка сценариев

## Ценность

Сейчас `/scenarios` (`src/app/scenarios/page.tsx`) — заглушка с пустым `<ul>`. Эта стори наполняет её списком опубликованных сценариев из публичного агрегата, той же механикой, что в МП (**A-10/A-12**).

## Контекст и трассировка

| ID | Документ | Как используется в этой стори |
|----|----------|-------------------------------|
| FR-W-2 | БТ | Навигация по контенту на сайте |
| A-10 / A-12 | СТ | Чтение публичных агрегатов контракта |
| A-10b | СТ | Бюджет чтений при билде |
| SR-SEO-1 | СТ | SEO-требования |

## Детали поведения

- Страница читает `sitemap_public/main` через `getSitemap` (`src/lib/contract/repository.ts`) → `scenarioEntries` (slug + id).
- Для каждого сценария — карточка со ссылкой на `/scenarios/[slug]`.
- Заголовки/подзаголовки — из `home_feed/main.vitrine` (если сценарий в витрине) или из `scenario_public/{id}` (без N+1 — см. ниже).
- Медиа (imageRef) — через `SupabaseImage` / `supabasePublicUrl` (**ED-14**).
- Окружение — `NEXT_PUBLIC_ENV` (dev/prod), механика как в МП (**A-26a**).
- SSG-рендер на сервере — контент доступен для индексации (**SR-SEO-1**).

## Вне scope

- Деталки сценария — **US-E4-01** (реализованы).
- Группы смысла на списке — **US-E10-01**.

## Критерии приёмки (AC)

- **AC-01** *(БТ FR-W-2, СТ A-10/A-12)*
  - Given опубликованные сценарии
  - When открыт `/scenarios`
  - Then отображается список всех опубликованных сценариев, соответствующий env.

- **AC-02** *(СТ A-10b)*
  - Given билд списка
  - When измеряется число чтений
  - Then 1–2 чтения на URL (без N+1).

- **AC-03** *(СТ SR-SEO-1)*
  - Given список
  - When собран
  - Then контент доступен для индексации.

## Зависимости и блокеры

- Агрегаты **E0** (реализованы).
- Деталки **US-E4-01** (реализованы).

## Открытые вопросы

- Откуда брать заголовки карточек: только из `sitemap_public` (slug) или подгружать `scenario_public`? Для соблюдения A-10b — предпочтительно из `home_feed/main.vitrine` (уже содержит title/subtitle/imageRef).

## Примечания для downstream

- Не читать `scenario_public/{id}` для каждого элемента (N+1). Использовать `sitemap_public/main` + при необходимости `home_feed/main.vitrine`.
