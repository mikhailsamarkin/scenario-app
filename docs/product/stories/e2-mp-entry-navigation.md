# Склейка МП: точка входа и навигация Home → Scenario → Game

## Ценность

Экраны витрины, сценария и игры реализованы и протестированы по отдельности, но не связаны в работающее приложение. Эта стори «склеивает» их: подключает главный экран как точку входа и создаёт навигацию **Home → Scenario → Game** (**A-15**), чтобы пользователь мог реально пройти основной путь (**UJ-1**).

## Контекст и трассировка

| ID | Документ | Как используется в этой стори |
|----|----------|-------------------------------|
| FR-M-1 | БТ | Главный экран — витрина сценариев |
| FR-M-2 | БТ | Экран сценария и игры, порядок блоков |
| A-15 | СТ | Навигация Home → Scenario → Game |
| A-11, A-38 | СТ | Чтение публичных агрегатов через репозиторий |

## Детали поведения

- При запуске приложение показывает главный экран (витрину) из `home_feed/main` (**A-11**, **A-38**).
- Тап по сценарию открывает экран сценария; тап по игре — экран игры (**A-15**).
- Экраны читают данные через реальный `AggregateRepository` (Firestore).

## Вне scope

- Онбординг первого запуска — **US-E3-01** (реализован отдельно).
- Офлайн/кэш/обновление — **US-E2-04/05/06** (реализованы).

## Критерии приёмки (AC)

- **AC-01** *(СТ A-15)*  
  - Given запуск приложения  
  - When открывается главный экран  
  - Then видна витрина сценариев из `home_feed/main`.

- **AC-02** *(СТ A-15, FR-M-2)*  
  - Given витрина  
  - When пользователь тапает по сценарию, затем по игре  
  - Then открываются экраны сценария и игры с данными из публичных агрегатов.

## Зависимости и блокеры

- Экраны **US-E2-01/02/03** (реализованы).
- Репозиторий чтения **E0** (реализован).
