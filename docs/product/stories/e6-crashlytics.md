# Crashlytics: отчёты о сбоях

## Ценность

Команда видит необработанные исключения и стектрейсы, что снижает время расследования инцидентов (**СТ A-41**).

## Контекст и трассировка

| ID | Документ | Как используется в этой стори |
|----|----------|-------------------------------|
| A-41 | СТ | Firebase Crashlytics |
| use-cases §6.2 | use-cases | Crash-free users/sessions |

## Детали поведения

- Crashlytics подключён к сборкам production (и при необходимости staging).
- Символикация для iOS/Android настроена для читаемых отчётов.

## Вне scope

- Алерты по Cloud Functions — до появления фоновых задач (**use-cases** §6.2).

## Критерии приёмки (AC)

- **AC-01** *(СТ A-41)*  
  - Given тестовый краш в сборке  
  - When приложение падает  
  - Then отчёт появляется в Crashlytics с корректным стеком.

- **AC-02**  
  - Given продакшен-сборка  
  - When мониторинг  
  - Then доступны метрики crash-free sessions/users в консоли.

## Зависимости и блокеры

- Firebase project, права доступа команды.

## Открытые вопросы

- Нет.

## Примечания для downstream

- Не логировать PII в кастомных ключах Crashlytics.
