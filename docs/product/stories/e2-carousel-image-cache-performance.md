# Производительность карусели и кэш изображений

## Ценность

Плавная карусель поддерживает восприятие качества приложения и снижает отказ от просмотра игры (**NFR-SR-6**, карусель **CR-5**).

## Контекст и трассировка

| ID | Документ | Как используется в этой стори |
|----|----------|-------------------------------|
| NFR-1 | БТ (в таблице E2) | Производительность UI |
| CR-5 | БТ | Карусель как часть контента |
| A-21a | СТ | Кэш изображений с лимитом диска |
| NFR-SR-6 | СТ | Производительность прокрутки/анимаций |

## Детали поведения

- Изображения карусели кэшируются на диске с ограничением по размеру (**A-21a**).
- Листание без заметных лагов на целевых устройствах (**NFR-SR-6**).
- Согласование с выбором библиотеки кэша (**ED-6**, **ED-13**).

## Вне scope

- Полная оптимизация всего приложения вне карусели.

## Критерии приёмки (AC)

- **AC-01** *(СТ A-21a)*  
  - Given повторное открытие игры  
  - When изображения уже загружались  
  - Then они берутся из кэша в пределах лимита диска.

- **AC-02** *(СТ NFR-SR-6)*  
  - Given карусель с типичным набором слайдов  
  - When пользователь листает  
  - Then нет систематических фризов: устойчивое листание ≥ 55 FPS (P95 время кадра ≤ 18 мс), доля пропущенных кадров < 5% за 20 свайпов вперёд-назад на целевых устройствах (портрет).

## Зависимости и блокеры

- Реализация экрана игры (**US-E2-03**).
- ADR по пакету кэша (**ED-13**).

## Открытые вопросы

- Закрыто: пороги приёмки AC-02 зафиксированы как индустриальные стандарты (см. AC-02 и тест-план): ≥ 55 FPS (P95 ≤ 18 мс), < 5% пропущенных кадров за 20 свайпов; целевые устройства — среднебюджетный Android (Snapdragon 7-й серии, напр. Pixel 6a) и актуальный iPhone (13+), портрет.
