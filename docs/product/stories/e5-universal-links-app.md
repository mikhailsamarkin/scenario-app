# Universal Links / App Links: открытие сценария в приложении

## Ценность

Установленное приложение перехватывает HTTPS-ссылку и открывает нужный сценарий (**СТ A-24**, **FR-M-7**).

## Контекст и трассировка

| ID | Документ | Как используется в этой стори |
|----|----------|-------------------------------|
| A-23, A-24 | СТ | Домен, AASA / assetlinks, universal links |
| FR-M-7 | БТ | Шаринг и открытие |

## Детали поведения

- Настроены файлы AASA (iOS) и Digital Asset Links (Android) для домена **`scenario-games.ru`**.
- Ссылка с путём сценария открывает приложение на экране сценария.

## Вне scope

- **Минимальный первый релиз** может ограничиться **US-E5-01** без полного UL (**use-cases** §5); полная приёмка — при включении E5 и сайта.

- Веб-fallback — **US-E5-03**.

## Критерии приёмки (AC)

- **AC-01** *(СТ A-24)*  
  - Given МП установлен  
  - When пользователь открывает HTTPS-ссылку на сценарий  
  - Then запускается приложение с нужным `scenarioId`.

- **AC-02** *(СТ A-23)*  
  - Given конфигурация домена  
  - When проверка ассоциации  
  - Then AASA/assetlinks валидны для стора/устройства.

## Зависимости и блокеры

- SSL, доступ к DNS, билд с корректными bundle id / package name.

## Открытые вопросы

- Нет.

## Примечания для downstream

- Координация с веб-редиректами **A-25** в **US-E5-03**.
