# Спецификация реализации — US-E3-01 «Онбординг: ценность „ситуация → игры“»

## 1. Scope

**В объёме:**

* **Онбординг первого запуска** в МП: короткий поток экранов, объясняющий модель «ситуация → подборка игр» (**UJ-4**, **A-17**, **AC-01**).

* **Опциональный запрос push** на шаге онбординга; отказ **не блокирует** переход к витрине (**AC-02**, **use-cases** E3).

* **Показ онбординга только при первом запуске** (флаг «онбординг пройден»).

* **Переход к витрине** после завершения онбординга (или сразу, если уже пройден).

* **Тесты**: widget-тесты онбординга (AC-01, AC-02).

**Вне scope:**

* Обязательная подписка на topic — **US-E3-02** (здесь только запрос разрешения, без реальной FCM-подписки).

* Дневные пуши — **US-E3-03**.

* Deep link из push — **US-E3-04**.

**Ключевые решения:**

* **Флаг «онбординг пройден»** (**A-17**): хранится локально (shared_preferences); при первом запуске показывается онбординг, далее — сразу витрина.

* **Поток ценности** (**AC-01**): короткие экраны «выбери ситуацию → посмотри подходящие игры» (русский, ED-2).

* **Push опционален** (**AC-02**): на шаге запроса пользователь может отказаться; отказ не блокирует переход к витрине.

## 4. Шаги (в порядке зависимостей)

### Шаг 1. Флаг «онбординг пройден»

* Локальное хранилище (shared_preferences): `onboarding_completed` (bool).

* При запуске: если флаг не установлен — показать онбординг; иначе — сразу витрину.

* **Реализовано:** `scenario/lib/features/onboarding/onboarding_prefs.dart` — `isOnboardingCompleted()`/`markOnboardingCompleted()` (shared_preferences).

### Шаг 2. Поток экранов ценности (AC-01)

* 2–3 коротких экрана: «Ситуация» → «Подборка игр» → «Выбирайте и играйте» (русский, ED-2).

* Кнопка «Далее» / «Пропустить».

* **Реализовано:** `scenario/lib/features/onboarding/onboarding_screen.dart` — `OnboardingScreen` (3 шага ценности + шаг push).

### Шаг 3. Запрос push (AC-02)

* На финальном шаге — запрос разрешения на уведомления (опционально).

* Кнопки «Разрешить» / «Позже»; отказ не блокирует переход к витрине.

* Реальная FCM-подписка — **US-E3-02** (здесь только UI-запрос).

* **Реализовано:** шаг «Уведомления о новинках» с кнопками «Разрешить»/«Позже»; обе ведут к завершению.

### Шаг 4. Переход к витрине

* После завершения онбординга — установить флаг и перейти на `HomeScreen` (витрину).

* Если флаг уже установлен — сразу витрина.

* **Реализовано:** `ScenarioApp` в `app.dart` — при первом запуске онбординг, затем `Navigator.pushReplacement` на витрину; флаг помечается.

### Шаг 5. Тесты

| AC    | Слой  | Проверка                                             | Где                          |
| ----- | ----- | ---------------------------------------------------- | ---------------------------- |
| AC-01 | widget | Онбординг объясняет «ситуация → игры»                | widget-тест онбординга       |
| AC-02 | widget | Отказ от push не блокирует переход к витрине         | widget-тест онбординга       |

* Widget-тесты: показ онбординга при первом запуске; после отказа от push — доступ к витрине.

* **Реализовано:** `scenario/test/onboarding_screen_test.dart` — 3 теста (AC-01, AC-02, «Пропустить»).
