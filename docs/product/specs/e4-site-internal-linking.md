# Спецификация реализации — US-E4-02 «Перелинковка сценариев и игр на сайте»

## 1. Scope

**В объёме:**

* **Ссылки со страницы сценария на игры** подборки (**FR-W-2**, **AC-01**).

* **Ссылки со страницы игры на связанные сценарии** (**FR-W-2**, **AC-01**).

* **Без N+1 при билде** — данные из агрегатов (**A-10b**, **A-10d**, **AC-02**).

* **Тесты**: контракт-тесты и проверка билда.



**Вне scope:**

* CTA установки приложения — **US-E4-03**.

* Бюджет запросов при билде — **US-E4-04**.

* Core Web Vitals — **US-E4-05**.

##  ​3. Архитектура данных

```mermaid
flowchart TD
  subgraph SITE["Next.js SSG"]
    SCEN[scenarios/[slug]]
    GAME[games/[slug]]
  end

  SCEN -->|slug игр из scenario_public.games| GAME
  GAME -->|slug сценариев из game_public.scenarios| SCEN
```

**Ключевые решения:**

* **Сценарий → игры** (**AC-01**): `ScenarioClient` рендерит игры со ссылками `/games/{slug}` из `scenario_public.games` (без N+1, A-10d.

.

* **Игра → сценарии** (**AC-01**): `GameClient` рендерит связанные сценарии со ссылками `/scenarios/{slug}` из `game_public.scenarios` (без N+1, A-10d.

.

* **Без N+1** (**AC-02**, **A-10b**): данные уже в агрегатах; дополнительных запросов на URL нет.

.

##  ​4. Шаги (в порядке зависимостей)

### Шаг 1. Ссылки со сценария на игры

* **Реализовано:** `ScenarioClient.tsx` — каждая игра подборки обёрнута в `<Link href={/games/${game.slug}}>`.

.

### Шаг 2. Ссылки со игры на сценарии

* **Реализовано:** `GameClient.tsx` — блок «В сценариях» со ссылками `/scenarios/{scenario.slug}` из `game_public.scenarios`..

### Шаг 3. Тесты

| AC    | Слой  | Проверка                                             | Где                          |
| ----- | ----- | ---------------------------------------------------- | ---------------------------- |

| AC-02 | unit    | Без N+1: данные из агрегатов                        | контракт-тесты               |
