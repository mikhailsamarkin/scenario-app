# Спецификация реализации — US-E7-02 «Сценарии прошлого»

## 1. Scope

**В объёме:**

* **Раздел «Сценарии прошлого»** на главном экране: архивные группы смысла (`isPastArchive: true`) (**CR-3**, **FR-M-1**).

* **Отсутствие дублирования** с активной витриной (**AC-02**).

* **Аналитика `source=past`** при открытии сценария из архива (**TC-04**, **US-E6-02**).

* **Тесты**: widget-тесты раздела и отсутствия дублей.

**Вне scope:**

* Редизайн по Figma — **US-E9-01**.

* Активные группы смысла — **US-E7-01** (реализована).

## 2. Требования → шаги

| #  | Требование                                                        | Источник          | Шаги |
| -- | ----------------------------------------------------------------- | ----------------- | ---- |
| R1 | Снятый сценарий доступен в «Сценарии прошлого»                    | AC-01, CR-3       | 1–2  |
| R2 | Нет дубля между витриной и «прошлым»                              | AC-02, CR-3       | 2    |
| R3 | `source=past` при открытии из архива                              | TC-04, US-E6-02   | 3    |

**Ключевые решения:**

* **Архив = группы с `isPastArchive: true`** (контракт уже есть в `SemanticGroupPublic`).

* **Раздел на home**: под активными группами — «Сценарии прошлого» с архивными группами.

* **`source=past`**: при открытии сценария из архивной группы передаётся `ScenarioOpenSource.past`.

## 4. Шаги (в порядке зависимостей)

### Шаг 1. Данные

* Пометить архивные группы `isPastArchive: true` в фикстурах.

* **Реализовано:** поле `isPastArchive` уже в контракте и фикстурах; добавлено в `GroupRef` (Dart) и `home_feed.groups` (импорт).

### Шаг 2. Раздел на home

* `home_screen.dart`: разделить группы на активные и архивные (`isPastArchive`); архивные — в секции «Сценарии прошлого».

* **Реализовано:** `home_screen.dart` — секции «Подборки» (активные) и «Сценарии прошлого» (архивные).

### Шаг 3. Аналитика `source=past`

* `app.dart`: при открытии сценария из архивной группы — `ScenarioOpenSource.past`.

* **Реализовано:** enum `ScenarioOpenSource.group`/`past` добавлены; `_GroupRoute` получает `source` из home (`group`/`past`).

### Шаг 4. Тесты

| AC    | Слой  | Проверка                                             | Где                          |
| ----- | ----- | ---------------------------------------------------- | ---------------------------- |
| AC-01 | widget  | Архивная группа видна в «Сценарии прошлого»          | widget-тест home             |
| AC-02 | widget  | Нет дубля с витриной                                 | widget-тест home             |
| AC-01 | unit    | `source=past` при открытии из архива                 | unit-тест сервиса            |

## 6. Риски

* **Как home узнаёт об архиве** — `GroupRef` не содержит `isPastArchive`. Митиг: добавить поле в `GroupRef` или отдельный список архивных id.

* **Дубль с витриной** — митиг: разделение групп на активные/архивные.
