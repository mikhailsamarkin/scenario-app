# Экран игры — макет и сопоставление с реализацией

Источник: фрейм `экран игры`
([Figma](https://www.figma.com/design/VBLmTqD6teTm3g8AJlU6mw/Scenario?node-id=0-1&p=f)).
Скриншот: [images/game.png](../images/game.png).

## Структура макета (сверху вниз)

### 1. Hero-карусель

- Фото на всю ширину (~410px), свайп между слайдами.
- Белая стрелка «назад» вверху слева (без AppBar).
- Справа внизу на фото — бейдж-пилюля с `caption` слайда: «**Партия в процессе**»
  (полупрозрачная тёмная).
- Внизу по центру — точки карусели (активная — терракотовая удлинённая).

### 2. Заголовок

- Кремовый фон, крупный тёмный serif «**Диксит**», тонкая линия-разделитель.

### 3. Секция «КРАТКО»

- Капс-заголовок «**КРАТКО**».
- Сетка **2×2** лавандовых карточек со скруглением; в каждой:
  - верхняя строка — иконка + подпись (приглушённая): «Игроки», «Время»,
    «Возраст», «Правила»;
  - снизу — жирное значение: «3–6», «Короткая партия», «Семейные»,
    «Быстро объяснить».

Соответствие полям `GamePublic`:

| Карточка | Поле |
|---|---|
| Игроки → 3–6 | `playersHint` |
| Время → Короткая партия | `durationBucket` |
| Возраст → Семейные | `ageHint` |
| Правила → Быстро объяснить | `rulesComplexity` |

### 4. Секция «ОПИСАНИЕ»

- Капс-заголовок «**ОПИСАНИЕ**» + абзац описания игры.

### 5. Кнопка «Назад»

- Широкая терракотовая кнопка внизу.

## Сопоставление с кодом (что менять)

Текущая реализация `lib/features/game/game_screen.dart`: AppBar «Игра»,
заголовок, контекст сценария, карусель (`PageView` по `GamePublic.carousel`),
характеристики как `Chip`, описание.

| Элемент | Сейчас | По макету |
|---|---|---|
| Шапка | AppBar | hero-карусель во всю ширину, стрелка поверх, точки на фото |
| Caption слайда | где-то под фото | бейдж-пилюля на фото справа внизу |
| Характеристики | плоский список `Chip` | сетка 2×2 с иконками и подписями |
| Кнопка «Назад» | нет | терракотовая кнопка внизу — **уточнить у дизайнера**: дублирует системную навигацию; возможно, имелось в виду «К сценарию» (возврат к подборке) |

Данные менять не нужно: `Slide.caption` и все 4 характеристики уже в контракте.

Функциональные требования SP-E2-03 (карусель AC-01/CR-5, переходы,
block_view) не меняются.
