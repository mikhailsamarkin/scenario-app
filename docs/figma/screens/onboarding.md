# Онбординг — макеты и сопоставление с реализацией

Источник: фреймы `onboarding 1.1`, `onboarding 2.1`, `onboarding 3.1`
([Figma](https://www.figma.com/design/VBLmTqD6teTm3g8AJlU6mw/Scenario?node-id=0-1&p=f)).

Скриншоты: [images/onboarding-1.png](../images/onboarding-1.png),
[images/onboarding-2.png](../images/onboarding-2.png),
[images/onboarding-3.png](../images/onboarding-3.png).

## Общая структура (все 3 экрана)

- Тёмный фон (баклажановый, см. [design-tokens.md](../design-tokens.md)).
- Верхняя половина — место под иллюстрацию: на фрейме 1 виден фото-коллаж
  (люди за настольными играми), на фреймах 2 и 3 область пустая —
  иллюстрации в макете нет (не загружена или осознанный «воздух» — уточнить).
- «**Пропустить**» — справа вверху, светло-серый мелкий.
- Внизу: 3 точки-индикатора (активная — удлинённая, терракотовая),
  затем капс-надзаголовок терракотовый, serif-заголовок белый, подтекст,
  кнопки на всю ширину.

## Экран 1

- Надзаголовок: `КАК ЭТО РАБОТАЕТ`
- Заголовок: `Выбери ситуацию — получи игру`
- Подтекст: `Не знаете, в какую игру сыграть? Просто выберите подходящий момент — а мы подберём под него настольную игру.`
- Кнопка: `Далее` (терракотовая)
- Активна точка 1.

## Экран 2

- Надзаголовок: `ЭКСПЕРТНЫЕ ПОДБОРКИ`
- Заголовок: `Подборки от людей, а не алгоритмов`
- Подтекст: `Каждый сценарий — это выбор редакторов, которые играют в настолки каждую неделю. Никаких рейтингов по кликам.`
- Кнопка: `Далее`
- Активна точка 2.

## Экран 3 (push)

- Надзаголовок: `БУДЬТЕ В КУРСЕ`
- Заголовок: `Новые сценарии — в уведомлениях`
- Подтекст: `Каждую неделю — новый сценарий. Разрешите уведомления, чтобы узнавать первыми.`
- Кнопки (две, обе на всю ширину):
  - основная терракотовая: `Разрешить уведомления`
  - вторая тёмная лавандовая: `Начать без уведомлений`
- Активна точка 3.

## Ключевые решения, которые фиксирует дизайн

1. **Три шага вместо четырёх**: текущий код (`lib/features/onboarding/onboarding_screen.dart`)
   содержит 3 ценностных шага + отдельный 4-й шаг запроса push. По макету
   шагов три, и третий — это сам push-запрос с явным выбором из двух кнопок.
2. **Тексты финализированы** и отличаются от кода:
   - код: «Выберите ситуацию / Получите подборку игр / Выбирайте и играйте» →
     дизайн: «Выбери ситуацию — получи игру / Подборки от людей, а не алгоритмов /
     Новые сценарии — в уведомлениях».
   - Шаг «Выбирайте и играйте» (про карусель и характеристики) из онбординга уходит.
3. Push-запрос остаётся опциональным (отказ не блокирует — согласовано с AC US-E3-02).

## Сопоставление с кодом (что менять)

| Элемент | Сейчас | По макету |
|---|---|---|
| Тема | светлая Material | тёмная брендированная |
| AppBar «Добро пожаловать» | есть | нет («Пропустить» в правом верхнем углу) |
| Шаги | 3 + push-шаг | 3 (третий — push) |
| Индикаторы | нет | 3 точки |
| Кнопки | FilledButton «Разрешить»/«Далее», TextButton «Позже»/«Пропустить» | «Далее», «Разрешить уведомления» + «Начать без уведомлений» |
| Иллюстрации | нет | место под иллюстрацию (источник ассетов — открытый вопрос) |

Функциональные требования US-E3-01/02 (завершение онбординга, опциональность
push, подписка на topic) не меняются — меняется только presentation-слой.
