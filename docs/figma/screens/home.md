# Home / feed — макет и сопоставление с реализацией

Источник: фрейм `home`
([Figma](https://www.figma.com/design/VBLmTqD6teTm3g8AJlU6mw/Scenario?node-id=0-1&p=f)).
Скриншот: [images/home.png](../images/home.png).

## Структура макета (сверху вниз)

### 1. Шапка (двухполосная, тёмная)

- Тонкая верхняя полоса тёмно-бордовая, под ней основная тёмно-фиолетовая
  (токены `header.plum`, `header.purple`).
- Логотип «**Scenario**» — белый serif.
- Заголовок «**Что сегодня?**» — белый serif, крупный.
- Подзаголовок «**Выберите сценарий — получите игру**» — приглушённый сиреневый.

### 2. Секция «Витрина»

- Заголовок «**Витрина**» слева (тёмный, bold), справа терракотовая подпись
  «**Редакторский выбор**».
- Горизонтальная лента крупных карточек (~55% ширины экрана, вертикальные,
  скруглённые): фото на всю карточку, снизу градиентное затемнение, поверх:
  - капс-категория терракотой («**ВДВОЁМ**», «**С ДЕТЬМИ**»);
  - белый заголовок сценария («Романтический вечер», «День рождения»).

### 3. Секции по категориям

- Заголовок секции — тёмный текст («**Вдвоём**», «**С детьми**»…).
- Под ним — карточки в стиле витрины, но компактнее (~40% ширины), судя по
  фрейму — горизонтальные ленты по одной на категорию.
- Нижняя граница фрейма обрезана на скриншоте: что ниже «С детьми»
  (ещё секции, футер, таб-бар) — не видно.

### Фон

Кремовый (`bg.cream`).

## Сопоставление с кодом (что менять)

Текущая реализация `lib/features/home/home_screen.dart` — `ListView` из
`ListTile` (48×48 превью + title/subtitle) со стандартным AppBar «Сценарии».

| Элемент | Сейчас | По макету |
|---|---|---|
| Шапка | AppBar «Сценарии» + иконка «О приложении» | брендированная шапка «Scenario / Что сегодня? / Выберите сценарий — получите игру» |
| Витрина | плоский список `ListTile` | горизонтальная лента крупных фото-карточек |
| Секции по категориям | нет | ленты по категориям («Вдвоём», «С детьми»…) |
| «Редакторский выбор» | нет | подпись у витрины |
| Офлайн/ошибка/загрузка | есть (AC-02) | сохранить, оформить в новой стилистике |

Функциональные требования SP-E2-01 (данные из `home_feed/main`, порядок с
сервера, переход на экран сценария, офлайн-состояние) не меняются.

## Изменения данных (главное)

См. [../data-changes.md](../data-changes.md): категории сценариев —
единственное содержательное изменение контракта, необходимое и для home
(секции), и для экрана сценария (капс-надпись в hero).

Вопрос управления: секции как структура в `home_feed` (управляемо с сервера,
дороже) vs клиентская группировка по полю категории сценария (дешевле,
порядок секций фиксирован кодом). Решение не принято — открытый вопрос.
