# Экран сценария — макет и сопоставление с реализацией

Источник: фрейм `экран сценария`
([Figma](https://www.figma.com/design/VBLmTqD6teTm3g8AJlU6mw/Scenario?node-id=0-1&p=f)).
Скриншот: [images/scenario.png](../images/scenario.png).

## Структура макета (сверху вниз)

### 1. Hero-шапка

- Фото на всю ширину (~400px высотой) — то же изображение, что карточка
  сценария на home.
- Кнопка «назад» — белая стрелка вверху слева (без AppBar).
- Внизу фото — градиентное затемнение, поверх:
  - капс-категория терракотой: «**ВДВОЁМ**»;
  - крупный белый serif-заголовок: «**Романтический вечер**».

### 2. Интро-блок (кремовый фон)

- Курсивный serif-подзаголовок: «Когда хочется провести вечер вместе, но экран надоел»
  (поле `subtitle`).
- Справа — пилюля-кнопка «**Поделиться**» с иконкой share (US-E5-01).

### 3. Блок обоснования

- Капс-заголовок: «**ПОЧЕМУ ЭТИ ИГРЫ ПОДХОДЯТ**».
- Абзац: поле `whyTheseGames` («Эти игры созданы для двух человек — они не
  требуют большой компании и задают правильный темп. Лёгкая конкуренция,
  много смеха и разговоров. Идеальный формат на 30–60 минут.»).

### 4. Список игр

- Капс-заголовок: «**В ПОДБОРКЕ · 3 ИГРЫ**» — со счётчиком и склонением
  (1 игра / 2 игры / 5 игр).
- Карточки: светло-лавандовые скруглённые плашки во всю ширину:
  - слева квадратное фото-превью (~80px);
  - название жирным («Диксит», «Джайпур», «Лоскутное одеяло»);
  - чипсы характеристик: игроки («3–6 игр.», «2 игр.»), «Короткая партия»,
    «Быстро объяснить»;
  - шеврон вправо.

## Данные: что есть и чего нет

Есть в контракте (`ScenarioPublic` + `ScenarioGameRef`):
`title`, `subtitle`, `whyTheseGames`, `imageRef`, у игр — `playersHint`,
`durationBucket`, `rulesComplexity` (ложатся на чипсы 1:1).

Нет: **категория сценария** («ВДВОЁМ» в hero) — см. [../data-changes.md](../data-changes.md).

## Сопоставление с кодом (что менять)

Текущая реализация `lib/features/scenario/scenario_screen.dart`:
AppBar «Сценарий» + share-иконка в actions, заголовок/подзаголовок текстом,
«Почему эти игры подходят» как `titleLarge`, список игр — `ListTile` c
`shortDescription` в подзаголовке.

| Элемент | Сейчас | По макету |
|---|---|---|
| Шапка | AppBar | hero-фото с категорией и serif-заголовком, стрелка назад поверх |
| Поделиться | иконка в AppBar | пилюля-кнопка в интро-блоке |
| Чипсы характеристик | нет (shortDescription текстом) | чипсы players/duration/complexity |
| Счётчик игр | нет | «В ПОДБОРКЕ · N ИГРЫ» со склонением |
| `block_view`-трекинг | встроен (kBlockScenarioWhy / kBlockScenarioGames) | сохранить, перенести на новые блоки |

Функциональные требования SP-E2-02 (данные, порядок игр, переходы,
block_view) не меняются.
