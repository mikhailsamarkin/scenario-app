# Дизайн-токены (наблюдения по скриншотам)

> ВНИМАНИЕ: значения сняты по скриншотам фреймов на глаз, не inspect'ом.
> Перед реализацией сверить с Figma (Dev Mode) и перенести точные значения.
> Здесь фиксируется система в целом: палитра, типографика, формы.

## Палитра

| Токен | Наблюдаемое значение | Где используется |
|---|---|---|
| `bg.dark` | очень тёмный фиолетово-серый / баклажановый, ~`#2E2833`–`#241F28` | фон онбординга |
| `header.purple` | тёмно-фиолетовый ~`#5F2B4E` | шапка home |
| `header.plum` | тёмно-бордовый (тонкая полоса над шапкой) ~`#4A1B3D` | верхняя полоса home |
| `bg.cream` | кремовый ~`#F5EFE6` | фон контента home/сценарий/игра |
| `bg.cream.alt` | чуть темнее/светлее кремового (чередование секций) | секции «почему подходят», «описание» |
| `accent.terracotta` | терракотово-оранжевый ~`#C97B5D` | капс-надзаголовки, активная точка, основные кнопки («Далее», «Разрешить уведомления», «Назад»), «Редакторский выбор» |
| `card.lavender` | светло-лавандовый ~`#EDE6F2` | карточки игр (сценарий), карточки характеристик 2×2 (игра), кнопка «Начать без уведомлений» — темнее |
| `text.onDark` | белый / почти белый | заголовки на тёмном |
| `text.onLight` | почти чёрный | заголовки на кремовом |
| `text.muted.onDark` | светло-серый | «Пропустить», подтекст онбординга |
| `text.muted.onLight` | серо-фиолетовый | подписи в карточках характеристик, подзаголовок шапки |
| `chip` | лавандовый чуть темнее карточки | чипсы характеристик в списке игр |
| `overlay.hero` | градиент от прозрачного к тёмному внизу фото | hero-блоки home/сценария/игры |

## Типографика

| Роль | Шрифт | Наблюдение |
|---|---|---|
| Логотип «Scenario» | serif | белый, крупный (~28–32) |
| Заголовок экрана (home «Что сегодня?», название сценария/игры) | **serif с засечками** | крупный; на тёмном — белый, на светлом — тёмный |
| Заголовок hero (сценарий) | serif | белый поверх фото |
| Надзаголовок-капс (надзаголовки секций) | sans, caps, letter-spacing | терракотовый (онбординг) или тёмный (секции «КРАТКО», «ОПИСАНИЕ», «ПОЧЕМУ ЭТИ ИГРЫ ПОДХОДЯТ») |
| Заголовок секции («Витрина», «Вдвоём») | sans, bold | тёмный |
| Подтекст / тело | sans, regular | серо-фиолетовый на тёмном, тёмный на светлом |
| Интро сценария | serif, italic | тёмный, крупнее тела |
| Кнопка | sans, bold, белый | на терракотовом фоне |

**Открытый вопрос**: конкретные гарнитуры (например, Playfair Display /
PT Serif для заголовков + Inter/Roboto для текста) — снять из Figma.

## Формы и элементы

- Карточки со скруглением ~12–16px; фото-превью в списке ~80px квадрат, скруглённые.
- Точки-индикаторы (онбординг, карусель): активная — удлинённая пилюля терракотовая, неактивные — серые точки.
- Кнопки: полная ширина (онбординг, «Назад»), пилюли («Поделиться», бейдж caption).
- Чипсы: скруглённые пилюли на лавандовом.
- Hero-фото: на всю ширину, высота ~400px (сценарий ~400, игра ~410), затемнение снизу.
